# Archival association checkpoint

The 2014 discovery image of OGLE-2014-SN-094 places its variable flux on Gaia DR3 4662989888116855808, the source identified with the 2023 LMC nova ASASSN-23hd using SOAR. A local fit using 30 field stars gives a registration scatter near 0.03 arcsec. The OGLE light curve has three faint episodes in 2014–15. Published work on the earlier transient suggested an active galactic nucleus. This branch tests the association and distinguishes earlier variability from additional classical-nova eruptions.
