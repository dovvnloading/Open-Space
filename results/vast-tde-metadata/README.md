# VAST DR1 optical TDE metadata — proposed, not frozen

Question: can pre-specified radio measurements provide evidence for a sustained late rise following an independently selected optical TDE? Observing unit: published optical event × uniquely associated VAST radio source × distinct image/visit. This is metadata-only; no radio flux, image pixels, or outcome-based selection have been inspected. No numerical test, threshold, or science selection is frozen by this draft.

The full 30-object optical parent is Hammerstein et al. 2023, ZTF-I table 1 (https://vizier.cfa.harvard.edu/viz-bin/asu-tsv?-source=J%2FApJ%2F942%2F9%2Ftable1&-out.all&-out.max=100). The supplied table includes SIMBAD-provided positions not in the original table; position identities and uncertainties require independent checks. Featureless classifications remain included. The paper explicitly excludes AT2019eve as an uncertain TDE classification; it is not a hidden removal from the 30. This is a fixed optical paper sample, not a statistically complete set of all TDEs. `cohort-metadata.csv` retains all 30, including 29 without a VAST catalog source within 30 arcsec; no match is not an upper limit or evidence of survey coverage.

One position has a nearby source, AT2018hyz → 13894502, angular separation 0.7804 arcsec; association and positional uncertainty remain to verify. There are 11 distinct image IDs in 2023–2025 (`known-control-epoch-metadata.csv`). AT2018hyz is a known delayed radio-bright event and a positive control, not an unreported discovery (https://arxiv.org/abs/2407.12097; https://par.nsf.gov/servlets/purl/10435685). A 30 arcsec preselection is a broad candidate-association radius, not an acceptance threshold. It cannot validate ownership or exclude chance alignments. No other candidate can be claimed from this parent without deeper image-level work.

Before examining fluxes, the next protocol must define source association and uncertainty gates, exact early-epoch fit and last-two-visit prediction, noise/upper-limit treatment, matched nonvariable field controls, radio-prior and AGN/scintillation checks, trial count, and instrumental failure conditions. VAST DR1 paper https://arxiv.org/abs/2602.22739 examined 170 variability-selected cases (44 spurious), publishing 126 real detections including planets. Its machine-readable table and the full 170 selection rule must be checked before novelty claims; this has not yet been completed. Radio events in active galaxies, scintillation, seeing/beam and calibration changes can mimic a rise; two held-out visits are same telescope but disjoint observations, not independent instruments. Survey inclusion requires pre-existing detectable compact radio sources and excludes neighbors within 30 arcsec; a null is conditional on selection. Calibrated image retrieval and independent radio-frequency/epoch checks remain pending.
