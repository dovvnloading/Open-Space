# SDSS-V DR19 Milky Way Mapper

**The search did not validate a new unbound star.** Of 361 APOGEE coadds with absolute barycentric RV at least 650 km/s, 89 have a Gaia DR3 RV with formal uncertainty at most 15 km/s. Every one of those 89 disagrees with Gaia by more than 100 km/s. The other 272 lack this independent comparison at that precision. This is a conditional RV-discordance measurement. Binary motion, misidentification and pipeline failure can all produce discordance. An unbiased false-discovery rate for all 361 cannot be inferred.

The instrument totals count stars within each table. The direct intersection contains 9,229 SDSS IDs, giving 708,309 unique eligible sources across both instruments. The tail contains 501 distinct SDSS IDs with matching Gaia rows. The visit queries retrieved 311 BOSS and 1,074 APOGEE SDSS-V visits across these IDs, including alternate instrument observations. The 95% Wilson interval for 89/89 is 95.9–100%. For 0/1,315 in the APOGEE control it is 0–0.29%. Assignment to the all-speed control used a deterministic SQL checksum on SDSS ID, independent of RV. The control can overlap the screening tail. A single APOGEE control member did so. Neither the assignment nor its reported discrepancy fractions correct for selection into Gaia RVS.

The SQL selection requires source release `sdss5`, a positive Gaia DR3 ID, coadd S/N ≥15 and |RV| <5,000 km/s. BOSS requires 0 < formal RV error ≤25 km/s. APOGEE requires ≥1 good RV because its SDSS-V coadd formal error is commonly zero. The loose screen accepts |RV| ≥275 km/s, tangential speed ≥275 km/s using positive parallax with S/N ≥4, or tangential speed ≥275 km/s using the Bailer–Jones photogeometric median. The ranking rotates the ICRS velocity into the Galactic basis and adds solar motion (11.1, 248.5, 7.25) km/s. Targets enter follow-up if |Galactic-standard-of-rest line-of-sight velocity| ≥525 km/s, inverse-parallax point speed ≥550 km/s, or the speed evaluated at the photogeometric 16th-percentile distance ≥550 km/s. This last speed is a point evaluation rather than a velocity credible bound. This screen misses some marginally unbound stars and some distant stars moving predominantly transversely. DR17 re-releases and white-dwarf-specific CORV velocities are outside the sample. The parent result reports the dynamical models and priors used for quantitative follow-up.

## Reproduction

Run `python fetch_survey.py`, `python rank.py`, `python fetch_tail.py`, `python fetch_nn.py`, `python count_overlap.py` and `python audit.py` in this directory. The first five use Python's standard library. The audit uses NumPy, SciPy and Astropy. Raw SQL outputs and visit FITS files are downloaded into ignored `raw/`; the manifests give exact SHA-256 digests. SQL responses use SDSS sentinel −9999 for some missing quantities, including APOGEE SDSS-V visit catalog S/N. Treat that value as missing. RVs are barycentric throughout the SDSS tables. The reported line positions use vacuum wavelengths in the visit's pipeline-shifted frame. They act as gross consistency checks. Only the 11 spectra listed in the manifest received pixel-level diagnostics, and a single spectrum or finite visit baseline cannot establish a single star's systemic RV in all cases.

The tail CSVs hold screened measurements and Gaia astrometric covariances. Each row represents a lead or follow-up observation. The files under `audit/` retain stellar parameters, epoch/line diagnostics, independent comparison rows, neighbor searches, controls and input hashes. The public reference tables are [SDSS DR19 stellar RVs](https://www.sdss.org/dr19/mwm/data/rv/), [Astra access](https://sdss.org/dr19/mwm/astra/accessing-astra-files/), [Astra spectrum frame](https://sdss.org/dr19/mwm/astra/output-files/), [Gaia DR3 variability processing](https://doi.org/10.1051/0004-6361/202243964) and [Bailer–Jones distances](https://doi.org/10.3847/1538-3881/abd806).
