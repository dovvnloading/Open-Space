## Astrometry, colors and counterparts

- Every 6-MADσ local maximum inside each image’s usable annulus enters the search, even if absent in the first epoch or missing from the pipeline source catalog. Ninety-two of the 93 individual detections preferred fixed sky to the host in at least one same-passband epoch with ≥0.22″ host displacement. All nine of their distinct sky positions repeat. For each peak, the nearest source for a hypothesis had to lie within 0.10″, with a ≥0.08″ advantage over the alternative. We checked the full set of 14 off-visit image comparisons per trigger, including cross-band nearest neighbors, using a wider comparison region to retain boundary-crossing objects. A 0.10″ complete-linkage cut groups repeated detections. The widest group has a 0.094″ diameter, and the smallest gap between groups is 0.940″. [1,302 comparisons](tracks.csv) · [Source groups](sources.csv)
- The single-epoch peak was 3.274″ from LAWD 66 on April 21, 2025, at registered coordinates 257.863643°, −14.799260°. F164N forced flux was 0.802 ± 0.133 µJy. No other visit’s catalog contains a source within 0.8″ of either tested position. At the host-following location, subthreshold March 2024 and September 2025 apertures gave 0.595 ± 0.156 and 0.499 ± 0.189 µJy, while March 2025 gave −0.149 ± 0.135 µJy. At the same position, the F277W forced aperture gives 0.141 ± 0.029 µJy. Neither the F277W pipeline catalog nor the independent blind search resolves a counterpart there. The nearest Gaia and PS1 entries are 1.067″ and 1.069″ away from fixed sky. Extrapolating the host-relative offset to the historical catalog epochs gives 0.503″ and 2.323″ to the nearest entries respectively. The two-band minimum model χ² is 13.68 at the Gaia distance with the adopted errors. Field crowding, azimuth-dependent residuals, or a transient can affect single-epoch peaks. Its origin remains open. [Forced fluxes and independent catalog distances in all 16 images](unmatched_forced.csv)

Dropping the trigger visit gives 0.030 µJy (28.39 for 6) and −0.151 µJy (3.53 for 6) respectively. The remaining host-track data do not repeat the 0.802 µJy trigger flux. ## Reduction and evidence

1. We paired all 16 PUBLIC MAST Level 3 mosaics with their pipeline catalogs, retaining MAST numeric observation IDs, exposures, URIs and raw query responses for programs 2692, 4519 and 6584. STScI cloud object listings supply sizes, change dates and multipart ETags. The 32 verified products total 5,363,177,794 bytes. All input SHA-256 digests are frozen, and each of these products separately matched the STScI listing’s multipart ETag. The four calibrated detector exposures used to check the single-epoch peak have a separate manifest. Narrowband pupils F164N and F323N set the effective passbands of the F150W2/F164N and F322W2/F323N combinations. [Input manifest and receipts](inputs.json)
2. We identified the bright nearby white dwarf using the DR3 proper motion, independently centroided it on each calibrated mosaic, and resampled each native SCI/WHT cutout at 0.031″ or 0.063″. To register the common field, we used outlier-clipped translation fits to compact sources 7–50″ from the host, with the first F164N image defining the reference. Each other mosaic retained 105–194 ties with 0.006–0.016″ radial RMS. Host-relative positions include the observed parallax as well as proper motion. Single-epoch aperture and Gaia extrapolations have additional WCS, parallax and blend uncertainties. [Epoch metadata](epochs.csv)
3. The adapter calls the merged white-dwarf search’s sky grid, difference-of-Gaussians response, local-maximum finder, subpixel refinement, injection iterator and fixed/background classifier. Local medians and MADs are measured in radial bins. A visit-specific point-spread function comes from an isolated, pipeline-compact field star. We use its tapered 21×21 stamp scaled by the same-visit catalog host/reference flux ratio. For each tested ratio and position, we add its filtered response to the real data before applying the blind detection threshold. For paired trials we also require the same host-motion decision used on the real positions. Zero-signal controls prevent a pre-existing recovery from counting. Each epoch and each baseline have discrete curves, with no interpolation, global mass limit or all-azimuth completeness assertion. [Reproducible reducer](reduce_lawd.py)

## Unresolved F164N signal: decisive test

The 2025-04-21 **F164N** maximum at **3.274″** is **unclassified**, not a co-moving planet. A future **NIRCam/F164N** epoch, for example **2028-04-21**, should test the **co-moving prediction E +0.344″, N +3.256″ from the Gaia-propagated white-dwarf position**, as well as the competing 2025 **fixed-sky** source location **RA 257.863643°, Dec −14.799260°**. The new date is a proposed observation, not an approved schedule; propagate Gaia proper motion and parallax for the actual epoch. Demand independent dithers, a new centroid and empirical injection recovery around the reported **0.8 µJy** signal before using a nondetection or a repeat to classify it. The position assumes negligible orbital curvature. [Independent referee review](../REFEREE_REVIEW.md).

## Replay

Install Python with NumPy, SciPy, pandas and Astropy. From the repository root set FIELD to this directory and CACHE to an empty writable data directory. The archived Sonora model table is fetched on first use and verified against SHA-256 2198426d1ca0e410fda7b63c3b7f45f3890a8d9f2fcf0a3a1e36e14185283ca5 from the merged campaign. External queries can be replayed offline using their deposited responses.

```sh
python "$FIELD/fetch_lawd.py" . "$CACHE"
python "$FIELD/field_archives.py" .
python "$FIELD/reduce_lawd.py" . "$CACHE"
python "$FIELD/dither_check.py" . "$CACHE"
```

The limits apply to point-like sources at the stated passbands, sampled radii and eligible angles, for the tested nearly constant projected offset. The measurement uses archive-calibrated Level 3 pixels. Reprocessing the full series from uncalibrated exposures, archival images absent from the footprint query, separations below 2″ or above 5″, appreciable orbital curvature and any variability between epochs fall outside these constraints. A weaker or varying source can remain unclassified. No object passed the co-motion selection for discovery validation.
