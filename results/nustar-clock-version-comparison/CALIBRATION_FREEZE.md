# Frozen calibration-only comparison
Freeze 2026-11-17 after observing metadata and calibration headers, before evaluating correction values: compare v234, v235 and v236 at 60-second intervals from 2026-10-10 02:00:01 UTC up to 07:50:00 UTC, plus last endpoint. This as-flown envelope deliberately includes gaps, not actual GTIs. Convert UTC to TT using astropy and MJDREFI/MJDREFF in each header; compare only when all three curves bracket a time. Evaluate FITS NU_FINE_CLOCK cubic Hermite control knots using CLOCK_OFF_CORR and CLOCK_FREQ_CORR (derivative); clock offsets are to be added to timestamps. Report each model coverage, maximum bracketing gap, pairwise signed min/max and absolute max in microseconds. These are sampled extrema, not analytical bounds; no extrapolation. No quality gate is inferred from a bracketing gap unless a threshold is independently documented. Recorded CLOCK_ERR_CORR is not an independently established phase uncertainty. Use same input epochs, calibration version and code hash; no event photon array access. A constant offset has no effect on within-observation coherence, so report the change about the first sample as well. 33 ms Crab period is for scale only; viable independent timing/ephemeris and statistical detection sensitivity remain unresolved.
