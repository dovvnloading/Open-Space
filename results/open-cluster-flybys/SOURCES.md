# Source data and extraction

Downloaded 2026-11-15 UTC. Gaia source IDs are integers. Read the Source column as a string or 64-bit integer to preserve every digit.

| File | Source and exact selection |
|---|---|
| inputs/hunt_reffert.csv | The 7,167-row VizieR table J/A+A/686/A42/clusters. Read all columns. Use Type=o, dist50<2000, n_RV≥7, e_RV<4, CST>5, CMDCl50>0.5, probJ>0.5 and retain the 622 matching rows. RAdeg and DEdeg are RA_ICRS and DE_ICRS at epoch 2016.0. dist50 is the parallax-based maximum-likelihood distance in pc. The distance modulus and photometric distances are different quantities. [Hunt & Reffert catalogue](https://vizier.cfa.harvard.edu/viz-bin/VizieR?-source=J/A%2BA/686/A42/clusters) |
| inputs/ucc_centres.csv, inputs/ucc_members.csv | UCC release 260615, 18,299 clusters and 1,094,716 membership rows. Select the five shortlisted pairs by normalized primary name. Preserve all membership rows in these ten clusters, and all RV entries including blanks. Positions and proper motions are in ICRS. The UCC publishes median astrometric parameters for its own list of members. The baseline bootstrap uses those individual Gaia measurements. [Perren et al. release](https://zenodo.org/records/20705026) |
| inputs/published_pairs.csv | Extract the ordered cluster names and the time (Myr) from all 490 eight-column body rows in Table 1 of the electronic appendix to *On the Encounter Rate of Open Star Clusters*. This table's time column spans 0–32 Myr. [Full text, version 1](https://arxiv.org/html/2509.00471v1) |
| inputs/other_groups.csv | Palma et al. J/A+A/693/A218 tables 2 and 3 and Liu et al. J/A+A/702/A48 tables 2 and 3. Store the primary name and numeric HR24 cluster ID for every group and pair entry. Deduplicate within a group. The files contain 617 + 400 pair systems and 261 + 82 groups. [Palma VizieR](https://vizier.cfa.harvard.edu/viz-bin/VizieR?-source=J/A%2BA/693/A218) · [Liu VizieR](https://vizier.cfa.harvard.edu/viz-bin/VizieR?-source=J/A%2BA/702/A48) |
| inputs/spectroscopic_matches.csv | VizieR V/164/stellar5 and III/286/catalog. Query each of the eight highlighted UCC centroids with a 1.4 degree cone. For LAMOST retain ObsID, position, HRV, e_HRV and snrg. For APOGEE retain APOGEE, position, GaiaEDR3, HRV (VHELIO_AVG), e_HRV, s_HRV, Nvis, SNR and SFlag. Crossmatch all targets to the nearest UCC member within 1.5 arcsec and require equal Gaia ID where the APOGEE ID is present. Preserve duplicate visits and sources with blank RV. For per-star medians first take the median across measurements of one source. The two catalogues use different velocity pipelines and calibrations. The matched spectra are a diagnostic outside the primary estimated orbits. [LAMOST DR5](https://vizier.cfa.harvard.edu/viz-bin/VizieR?-source=V/164/stellar5) · [APOGEE DR17](https://www.sdss4.org/dr17/irspec/radialvelocities/) |

The additional snapshot inputs/tarricq_rv.csv retains the four available 2021 systemic velocities among the eight highlighted clusters, their reported errors and the number of selected sources. [Tarricq et al.](https://vizier.cfa.harvard.edu/viz-bin/VizieR?-source=J/A%2BA/647/A19/orbits)

The Harvard VizieR service accepted an ASU-TSV GET with `-source=J/A+A/686/A42/clusters`, `-out.all=1` and `-out.max=unlimited`. Encode the literal plus signs in the catalogue identifier as %2B. UCC upstream SHA256 hashes are dfed72e9469dbf786ff1d0708c836aee356cde66dd1ea26531bebe143532a235 for UCC_cat.csv and e8f88a8ce10a425687759bf477c9b3b44f0f86b832552d90124aec639fa988c2 for UCC_members.parquet. The release's published parquet MD5 is 39d5affdf141bd4f2dbad6ae00435e15.

The science replay used Python 3.12, NumPy 2.3.5, pandas 2.2.3 and SciPy 1.17.0. The Galactic integration used galpy 1.12.1 and astropy 8.0.2. The plot used matplotlib 3.10.8. [MWPotential2014 documentation](https://docs.galpy.org/en/stable/reference/potentialmw.html)
