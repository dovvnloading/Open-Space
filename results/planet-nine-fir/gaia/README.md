# Gaia DR3 observing geometry

We queried both fields of view in Gaia's commanded scan law (2014–2017). Among 243 broad field passages in the acquisition rectangle, 88 pass within 0.40° of at least one direction in the nominal Phan orbit grid. The file gives a representative time, the RA/Dec envelope at that time, the minimum sampled separation and the number of tracks meeting that angular screen. Field size, spacecraft attitude, mission gaps, window assignment, detection and downlink affect whether a transit produces data. The 0.40° criterion is an acquisition screen; it does not certify photons at a position. Gaia DR3 source lists contain selected detections. No Gaia injection-calibrated upper limit follows. Both input responses are hashed and compressed for replay. [ESA data model](https://gea.esac.esa.int/archive/documentation/GDR3/Gaia_archive/chap_datamodel/sec_dm_auxiliary_tables/ssec_dm_commanded_scan_law.html) · [Field passes](nominal_passes.csv)

Run scan_epochs.py with Astropy, NumPy and pyerfa. The orbit grid uses a geocentric proxy for Gaia at L2, adequate for selecting field approaches. Epochs are converted from the archive's TCB time convention. Frame windows and actual scan coverage have not been reconstructed.
