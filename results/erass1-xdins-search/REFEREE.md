# Independent adversarial referee — eRASS1 DR1 XDINS screening

**Verdict (19 November 2026): accept as a transparent, bounded screening/pipeline measurement, reject any discovery claim or calibrated null.** This check is an intentionally separate reading of the saved official input receipts, candidate tables, control positions and failure modes; it does **not** claim to be independent sky-image or spectral confirmation. It tests the result *against* the proposal to discover a new XDINS rather than accepting a zero-candidate assertion by default.

## Audited assertions

1. **Input identities/receipts:** The first run obtained main **v1.2** (930,203 rows) and hard **v1.0** (5,466 rows) FITS with two-layer archive/member SHA-256, HTTPS 200 and release URLs; the exact files/bytes/ETags appear in [receipts](output/receipts.json). The follow-up independently obtained **LS10, GDR3 and CW2020** release files and member hashes with HTTP 200 in [official receipts](output/official_receipts.json). This is actual public-data processing, not a fabricated download or HEASARC subset.
2. **Denominators:** Independently compare [candidate_screen](output/candidate_screen.json), [screened_main.csv](output/screened_main.csv) and [official_followup](output/official_followup.json). The fixed gates are monotone **930,203 → 75,645 → 61,624 → 1,659 → 1,330**. Eleven of 1,330 are flagged as close to a >5× brighter neighbour, leaving **1,319**. **1,056+274=1,330** and **25+35=60**. These are source/association counts, not object-class classifications.
3. **Positive controls:** In the public eRASS1 western hemisphere, each of RX J0420.0−5022, RX J0720.4−3125, RX J0806.4−4123, RX J1308.6+2127 and RX J1856.5−3754 has a nearest main-catalogue source **within 6.3 arcsec and passes the frozen screen**. RX J1605.3+3249 and RX J2143.0+0654 are outside the data-rights hemisphere, **not sensitivity failures**. The published eRASSU J065715.3+260428 and the 2026-confirmed XDINS eRASSU J131716.9−402647 also pass. This is a meaningful source-level control but no recovery-completeness estimate across flux/absorption.
4. **Optical verification reverses an unsafe inference:** The first ten CDS cone-match requests **all timed out**, so 0/60 matches in the initial [candidates.csv](output/candidates.csv) is **INVALID as a non-match statement**. Independent official-table exact-X-ray-UID joins instead report **25/60 high-probability counterparts**. The analysis retains the failure receipts rather than retroactively calling those 60 blank fields discoveries. For all 1,330, **1,056** secure associations and **274** no-secure-association cases are *not* an estimate of neutron-star prevalence.
5. **Near-IR/optical colours and photo-z:** LS10 release provides NWAY probabilities, PSF g depth, AGN colour flags, photometric redshift, HamStar coronal classification and optical photometry *for published counterpart records*. They are not meaningful at a position without credible association. Gaia and CatWISE tables provide separate links; the Gaia release fields requested as `parallax`, `pmra`, `pmdec` were absent by those names (see receipt), so those tests are not certified. A near-coincident catalogue object can be a chance alignment; p_any ≥0.8 is not a zero-false-match truth label.
6. **Optical flux ratio is NOT proven:** For a given X-ray flux, the recorded `g_equals_V_required_for_1e4` is the *required magnitude*, not a surveyed limit. Only 18/60 have a documented LS g-depth value on the *counterpart row*, and even then the (V)-band equation cannot be treated as a calibrated (g)-band flux ratio. All 60 remain **without any certified (f_X/f_{opt}>10^4) assertion**. Coverage gaps and foreground extinction are not incorporated.
7. **No independent classification:** Blackbody (kT=40–120) eV fits, NH, pulsations, observation-to-observation variability, source-product image inspection, native XMM/Chandra/Swift spectra/timing, current ATNF and the full Kurpas et al. (2024) 33-object literature list have **not been completed**. Several visible bright Magellanic-Cloud-area objects have numerous possible environmental contaminants; soft broad-band counts alone cannot distinguish neutron stars from supersoft stars, white dwarfs, stellar coronae or background AGN.
8. **Selection bias:** The 60 follow-up targets were chosen by high X-ray counts × softness, not unbiased or sky-depth-weighted random sampling of the 1,330, let alone of all 930,203. Thirty-five not securely associated in three catalogues are not independently new. No injection/recovery or random-position false-association control has been conducted. **No population rate, detection completeness or calibrated null can be inferred.**

## Integrity and decision

The separate [machine referee](output/referee.json) confirms **11/11** protocol, row-count, monotonicity, and output consistency tests, and explicitly *does not* certify novelty, spectroscopy, timing, population sensitivity or optical limits. Our independent arithmetic is consistent with those files and highlights the false “0 optical counterparts” conclusion that would have arisen if network failures were silently treated as astrophysical absences.

**Outcome:** File as an *inconclusive bounded null on independent discovery validation*, **not** a discovery-level scientific finding or calibrated XDINS search null. No [REMARKABLE] label or log entry. The correct next work would be per-target depth/forced-photometry tests, 2024–26 literature masking, archival image/spectrum/timing reduction and a quantified selection function. Until then there is no defensible novel XDINS.
