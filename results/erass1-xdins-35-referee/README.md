# eRASS1 top-35 unresolved XDINS follow-up — no new discovery demonstrated

**Pre-analysis decision boundary (19 Nov 2026):** Follow up all **35** top-60 eRASS1 sources that PR #204 lacked a secure Gaia/Legacy/CatWISE association for. This is not a set of 35 optical nondetections. Four are already-known Magnificent Seven XDINS (RX J0720, RX J0806, RX J1308 and RX J1856), hence cannot be discoveries. The other 31 are **unclassified pending direct measurements**, not presumed AGN or INS. This result will not claim a new INS unless independent deep image limits establish a robust f_X/(nu f_nu) lower bound >10^4, thermal X-ray response-fitting beats AGN/coronal models, X-ray timing and repeat observations support stability, and prior literature is excluded.

The [single branch-scoped job](../../.github/workflows/erass1-xdins-35-followup.yml) retrieves image pixels and archives on a network-enabled Actions runner, never treating catalogue non-matches or failed HTTP requests as photometric limits. It executes only when this folder's analysis source/dependencies change; generated output is excluded. See [source-level classifications](output/classifications.csv), [photometry and provenance](output/image_receipts.json), [full source evidence](output/source_evidence.json), [archive query receipts](output/archive_receipts.json), [ATNF](output/atnf_receipts.json), [literature](output/literature_receipts.json), and [independent evidence-level referee](REFEREE.md).

**Falsification controls:** the four known XDINS must remain known, any uncalibrated/undetected image position must have no invented flux-ratio bound, and an archival-query failure must never become a claimed nondetection. Flux lower limits (when an actual g-band stack is measured) use the observed 0.2–2.3 keV flux divided by 5-sigma AB g-band nu*fnu, not a substituted V-band Maccacaro relation. Values are provisional because the fixed-aperture estimate is not a PSF-fit, dust-corrected optical limit or unabsorbed X-ray model. The catalog-softness proxy is **not** a 40–120 eV blackbody spectrum fit.
