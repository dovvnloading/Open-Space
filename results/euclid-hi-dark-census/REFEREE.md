# Independent referee report: Euclid DR1-F × blind-H I coverage study

**Scientific verdict (19 November 2026):** Accept the reproducible *geometric eligibility inventory* as a limited technical result. **Reject any proposed starless-galaxy detection, dark-galaxy occurrence rate, stellar-mass upper limit, or dynamical-mass inference.** No claim meets the repository's `[REMARKABLE]` bar. The result README must remain explicitly coverage-only.

## Cross-check against frozen output and code

- The acquired table denominators are 31,502 ALFALFA alpha.100, 156,411 FASHI DR2 and 3,454 public WALLABY pilot DR2 table rows, totalling **191,367 rows**. Every catalogue status and the actual WIDE and DEEP MOC response is retained with source/query SHA-256 in `output/receipts.json`. The FASHI response matches the expected frozen SHA. The case-insensitive ALFALFA `logMH`/flux parser fix is tested. The complete three-table run is *not* the earlier failed WALLABY TAP attempt.
- The MOC rule gives **116+1 ALFALFA, 1222+36 FASHI and 0+0 WALLABY** center/edge-sample overlaps (1,375 positions). This is an *unduplicated row count only within each table*, **not** a count of unique HI systems across surveys. It is a possible beam–tile intersection, not a verified usable Euclid image footprint.
- The 16-point edge ring can miss contacts and MOC membership says nothing about VIS/NISP usable pixels, PSFs, photometric masks, depth or local cirrus. Euclid special/calibration footprints were not enumerated. Release completeness is bounded to the three frozen source tables, not every current ASKAP/FAST data product.
- A 32-source stratified diagnostic follow-up and **two** image positions do not meet the requested all-1,375 counterpart search. The query receipts expose network/VO service failures separately; nonresponses must never be recoded as optical absence. Exact spectroscopic redshift agreement (DESI/SDSS), robust photo-z, and deep extended-object searches remain unvalidated.
- The native-image code uses intentionally simplistic off-target apertures; it does not apply the Euclid segmentation/quality flags, PSF matching, dust extinction, masking or injection recovery. No `Mstar` upper bounds or meaningful gas-to-stellar ratio lower limits may be quoted. Computing a local diagnostic does not change this decision.
- Beam-smearing, split HI components and confusion, telescope RFI flags, Galactic HVC/nebular lines, tidal gas in velocity-matched groups, and angular size/inclination needed for dynamical mass remain untested. The cross-survey neighbor count is not an isolation test. Source IDs have not been exhaustively reconciled against AGC 229385, Cloud-9, FASHI 2026 dark candidates, AGC 322753 or WALLABY's H1032−2819.

## Disposition and reproducible next action

**PASS:** catalogue download provenance; all-row position/beam–MOC screen; transparent fixed numeric thresholds; source-level statuses and missing-data handling; one branch-only path-scoped data job; no unsupported discovery label. **FAIL:** physical classification and sensitivity completeness. A zero in the field `confirmed_starless_HI_galaxies` means **zero validated discoveries from this pipeline**, not zero starless galaxies in Euclid and not an incidence confidence interval.

For a defensible full study: deduplicate overlapping HI beams using redshift/uncertainty, verify native VIS/NISP coverage and flags for *every* surviving beam, perform forced multi-scale source+blank-aperture photometry and injection tests, infer Mstar limits over SED/distance uncertainties, crossmatch DESI/SDSS/photo-z, and inspect H I cube/line-profile, RFI, velocity-matched environment, resolved gas geometry, and previous literature for each potentially starless target. Only then consider scientific null rate or `[REMARKABLE]`.
