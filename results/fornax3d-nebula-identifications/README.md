# Thirty-six Fornax3D repeat observations with discrepant source identifiers

Four Fornax galaxies contain 36 **candidate corrections** to published links between repeat detections. For these cases the published central-pointing index refers to a substantially different location, while an isolated alternative agrees in sky position, velocity and [O III] brightness. The proposed corrections require raw-cube registration before they are treated as confirmed catalog errors. The median separation drops from 15.39″ for the published indices to 0.154″ for the alternatives. The table provides candidate corrected links for FCC 083 (4), FCC 161 (6), FCC 190 (4), and FCC 310 (22). Each link pairs two MUSE pointings. The emitting objects were already catalogued.

**FCC 083 H-1** illustrates the consequence for a repeat-velocity measurement. The published index C-42 lies 11.08″ away and differs by 158.3 km/s. C-40 lies 0.390″ away, differs by 3.5 km/s and differs by 0.20 mag. I checked the three source positions, velocities, and index labels against the authors' preprint table as well as the CDS export. In FCC 310, H-26 and its likely counterpart C-13 agree to 0.170″ and 11.5 km/s, but the two pointings assign different labels (PN and interloper). That classification remains open. [Author table](https://arxiv.org/abs/2107.09680) · [Published survey](https://doi.org/10.1051/0004-6361/202141314)

## Selection and replication

The 1,484 rows in the Spriggs et al. machine-readable source table include 107 named repeat links. The audit considers every link. It compares all detections in both pointings of the same galaxy, retaining the published coordinates and zero point. A proposed association requires a reciprocal nearest neighbor within 0.6″, the next alternative in **both** pointings beyond 2″, the named link beyond 3″, an absolute line-of-sight velocity difference below 30 km/s and a 5007 Å magnitude difference below 0.4. These exploratory cuts prioritize clean individual links. Velocity and magnitude are crosschecks from the same exposures. Rows outside those cuts remain in the audit. Another FCC 167 entry, F3D J033628.05−345815.65, has declination −14° in the tabulated coordinate column but −34° in its name. The paired central exposure supports −34°. No change to the paper's distances or luminosity function has been established.

The original search crossmatched the planetary nebulae to the 722 Fahrion et al. globular clusters. Taking PN-labelled entries without secondary-pointing aliases, 1,345 rows share a galaxy with the cluster catalog. Zero pairs pass both 0.5″ and 30 km/s. Moving the PN positions by 5″ in 24 directions gives 0–5 matches per offset. These correlated shifts are a density check. The catalog evidence supports no new hosted nebula in this sample. [Cluster survey](https://doi.org/10.1051/0004-6361/202037685)

Run `python audit.py` in this directory with NumPy and SciPy. It checks the input hashes and recreates the two result CSVs and the summary. The input CSVs are a fixed subset of columns of the VizieR TSV releases, in returned row order, with surrounding whitespace stripped. Use the [PN catalog](https://vizier.cds.unistra.fr/viz-bin/VizieR?-source=J/A%2bA/653/A167/catalog) and [cluster catalog](https://vizier.cds.unistra.fr/viz-bin/VizieR?-source=J/A%2bA/637/A26/gc-cat). Source attribution and reuse terms follow [VizieR](https://cds.unistra.fr/vizier-org/licences_vizier.html).

The proposed indices are an external audit. The strongest additional check would register the overlapping raw cubes to a common astrometric frame and re-extract the individual objects. A search of the source paper, its published software and indexed literature for a correction on 15 November 2026 did not locate a prior list of these links. The [authors' labeling script](https://github.com/tspriggs/MUSE_PNe_fitting/blob/master/scripts/other/cross_match_PN_ID.py) uses explicit row lists and positional indexing. Identifying the original cause requires the precise input tables used for publication.
