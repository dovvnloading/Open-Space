# Near-Earth asteroid pair search

## Question and falsification test

Can a search of the current JPL Small-Body Database recover two separately designated near-Earth asteroids with a plausible previously unreported recent fragmentation? The observing unit is a pair of distinct orbit solutions. A small distance between catalogued orbits alone gives a candidate. Phase-resolved integrations, orbit quality and the history of each designation decide whether the candidate merits physical interpretation.

Screen all available near-Earth asteroid orbits for similarity. Retain the search denominator, input digest, known-pair controls, time conventions and alternatives including short-arc degeneracy and duplicated identifications. Check the literature and ephemerides before interpreting a ranked pair. Publish a candidate's name and the reproducible evidence that supports or rejects that interpretation. This file records the question before ranking the data.
