# Search for coherent variability in Galactic methanol masers

The observing unit is a velocity-resolved time series of the 6.7 GHz methanol line toward a star-forming region. The public Ibaraki monitoring index includes observations from the Hitachi and Takahagi 32-m telescopes. The search asks whether a previously unreported flare cycle or systematic change in a cycle survives a chronological split. We will check the observing window, seasonal aliases, neighboring velocity channels and published periods before interpreting any candidate.

The repository's main-branch result folders, branch names and open pull requests were inspected on 15 November 2026. There were no open pull requests at the time of the initial check. Haumea satellite events and brown-dwarf radio counterpart work are excluded from this search.

[Monitoring index](https://vlbi.sci.ibaraki.ac.jp/iMet/)
