# NASA Ames classification and group membership

The published Ames bolide record identifies the 14 August 2026 Washington event in both G18 and G19, reports a high-confidence/isolated event classification in its public record and contains a **beginning altitude of 44.659 km**. Its attachment rows carry optical position, energy and UTC millisecond time for each selected group. The record examined on 2026-11-15 contains no field for the time-resolved peak altitude. [Ames event detail API](https://neo-bolide.ndc.nasa.gov/service/event/6a80a3b3f102fba8e7ba7a19) · [Published detection methods](https://doi.org/10.1029/2025EA004896)

All 421 Ames groups match distinct NOAA L2 groups in the broader 442-group cut. We used one-to-one coordinate and energy matching to recover identifiers, with absolute latitude/longitude tolerance 0.000001°, relative energy tolerance 0.000001, and a 2 ms time tolerance. The actual matched time offsets are within 1 ms. All 20 G18 and all 20 G19 groups in the 07:48:36.48–36.52 UTC peak bin survive the independent event selection. The resulting 31.85 km luminous-centroid reconstruction is identical. In the three earlier simultaneous NOAA bins, every G18 group survives and zero of 5, 6 and 5 G19 groups respectively survive. Those bins are exploratory and their physical association requires additional evidence. The published beginning-altitude field provides a separate prior report near the early reconstructed value. The catalog uses the same NOAA instruments; matching its classification tests group membership, without supplying an independent observation of the peak height. Unselected instrument detections can represent real light below algorithmic selection thresholds. [Per-bin membership counts](matches.json) · [Archived Ames selection](ames-groups.json)

Run `python check.py` in this directory to regenerate the membership table using the archived Ames rows and the NOAA rows in the parent folder. The optional `--download --selection /tmp/ames.json --output /tmp/ames-matches.json` requests the current public record. The selection includes exact source URLs for the API and CSV exports and the digest of the full API response used here.
