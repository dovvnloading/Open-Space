# Cosmic-ray source search in the March 2024 Auger open data

**Claim: inconclusive calibrated pilot — no validated new source or energy-ordered multiplet.** A six-event chain and broad Centaurus A/starburst directional excesses were found, but none survived the tested sky/energy controls at the discovery level. **This is not a complete five-catalogue null**: two requested catalogues and the separate published UHECR event catalogue were not analyzed.

## Dataset and release fraction

The latest listed [Auger open-data release](https://opendata.auger.org/data.php) is **2024-03-20 (release 3), DOI [10.5281/zenodo.10488964](https://doi.org/10.5281/zenodo.10488964)**; the version-independent DOI is [10.5281/zenodo.4487612](https://doi.org/10.5281/zenodo.4487612). Its reconstructed cosmic-ray samples contain **10% of quality-selected events** from the historically published detector samples (SD1500 to Aug 2018; SD750 Jan 2014–Aug 2018), **not 10% of all cosmic rays Auger has since observed**. The release also includes the separate **2023 published UHECR catalogue**, which was **not** downloaded in this pilot.

This pilot analyzed a GitHub mirror of the reconstruction summary CSVs, not the original archive bytes (the direct Auger and Zenodo hosts did not resolve in the local container). The curated, deduplicated event ledger contains **3,111** SD1500 + inclined events above 8 EeV, **493** above 20 EeV, **155** above 32 EeV, and **58** above 45 EeV; the low-energy SD750 array is excluded from statistical tests. Provenance: [original-hash manifest](receipts/hashes.json), [first-step host test](receipts/host-connectivity.md), and [official-Zenodo byte-check script](scripts/prepare_from_zenodo.py). Published upstream ZIP MD5 has **not** been directly verified against acquired bytes; only the third-party mirror's Git objects were accessible.

## Measured exploratory results (all p-values descriptive for this pilot)

| Check | Outcome | Interpretation |
| --- | --- | --- |
| First-harmonic right ascension, E ≥ 8 EeV | amplitude **0.025422**, phase **137.676°**, scrambled-sky **p=0.622** (999 scrambles) | Dipole **not significantly reproduced** in this 10%-scale subset; not a full exposure-weighted 3D dipole |
| Cen A within 27°, E ≥ 32 EeV | **28** events, sky-null mean **16.55**, local **p=0.005** | Known direction shows an excess, but not after all tested source trials |
| Five selected nearby starbursts within 25°, E ≥ 20 EeV | **172** events, sky-null mean **145.78**, local **p=0.006** | Pilot broad excess; **not** reproduction of the Auger published flux-weighted starburst catalogue/template |
| Full tested source scan: 1LHAASO (90), historical magnetars (30), young pulsars (173), Cen A, five starbursts | **39** energy-threshold/radius/catalogue configurations, **family-wise sky p=0.101**; within-detector-sample energy-shuffle **global p=0.101** | No trial-corrected new source. Best LHAASO local p=0.171; magnetars 0.028; young pulsars 0.008 |
| Approximate Auger-style inverse-energy multiplets | Largest chain **6** events (seed 99.034 EeV, five events 20–24 EeV), Pearson r=**0.94746**, extrapolated RA **89.796°**, Dec **−49.789°** | **Not significant:** sky max-multiplicity **p=0.233**, within-sample energy-shuffle **p=0.252**, each from 999 complete rescan controls |

Source-scan trials include E ≥ 20/32/45 EeV with catalogue radii 5°/10°/20°, Cen A 15°/27°, and five starbursts 13°/25°. Per-control scans reoptimize all tested configurations; one-sided p-values use the +1 Monte Carlo convention. Global p is the minimum empirical local p across 39 configurations compared against the same minimum statistic in each scrambled world. **These global probabilities do not include missing future catalogues, model variations, or the choice of searching for multiplets as a separate family**; conservative Bonferroni across the two sky-search families would not yield a signal. Right ascension is randomized while declination/energies remain fixed; energy labels are permuted separately within SD1500 and inclined samples.

The approximate [Auger multiplet method](https://doi.org/10.1016/j.astropartphys.2011.09.005) motivates the pre-cut E>20 EeV, >45 EeV seed, 20° extent, ≤1.5° transverse width and 1/E linear directional correlation r>0.9. Here the search tries every high-energy seed and nearby axis, permits up to two greedy deletions, redoes the full search for each null, and fits a zero-deflection direction. **No charge assignment, Galactic magnetic-field solution, or independent source identification** follows from this fit.

## Reproducibility, receipts and completed vs pending checks

- **Completed and committed:** first-step seven-host DNS test; curation of 3,111 event records; 90 first-LHAASO positions, 30 historical magnetars and 173 young ATNF pulsars; fixed Centaurus A and five illustrative starbursts; deterministic source scan and maximum-multiplicity search; 999 random-RA and 999 energy-shuffle controls per tested scan family; separate read of ledger, catalogue inventory and independent Cen A angular count; [referee audit](referee-check.md).
- **Pending / unable to verify:** primary Zenodo summary ZIP MD5 and Git-object byte equality; official 2023 published UHECR catalogue; all entries of **4LAC-DR3** (binary FITS blocked in text-only connector) and the **869-galaxy Updated Nearby Galaxy Catalog** (row data unavailable), full Auger flux-weighted starburst list, official acceptance/live-time exposure, 3D dipole, alternate multiplet implementation, physical GMF backtracking, source weights and uncertainties, comprehensive five-catalogue/global look-elsewhere control. **Do not report these pending analyses as completed or as negative detections.**
- **Data integrity:** [SHA-256/Git SHA-1 manifest](receipts/hashes.json) of committed ASCII inputs, program and computation results; original Zenodo metadata MD5 is listed as *unverified*. Git blob object IDs of the source mirrors are pinned.
- **Compute:** this was computed directly in an isolated JavaScript compute runtime through the connected GitHub data interface; **GitHub Actions were not used**. The standalone Node.js analyzer is [`scripts/analyze.js`](scripts/analyze.js). With the checked-out repository and Node 22+, run `node results/auger-open-uhcr-source-search/scripts/analyze.js` (999 trial controls by default; written to `receipts/`). To reacquire the authoritative ZIP in a network-enabled environment, use `python3 results/auger-open-uhcr-source-search/scripts/prepare_from_zenodo.py` or `--zip path/to/summary.zip`; that script fails closed on ZIP MD5 and mirrored raw Git SHA-1 differences.
- **Outputs:** [source and positive-control trial table](receipts/correlation_trials.json); [multiplet sky and energy null histograms, event IDs and fitted direction](receipts/multiplet_trials.json); [source access test](receipts/host-connectivity.md); [independent methods review](referee-check.md).

**Publication status:** inconclusive methods/feasibility record, **not a calibrated null for all requested source families**.
