# Archival soft-X-ray quasi-periodic eruption search (4XMM-DR14)

**Claim (pre-analysis): No new QPE discovery is established.** This is a newly initiated, bounded archival search. Its evidentiary status remains **pending** until the GitHub Actions data job writes receipts and validation outputs. A non-detection in a limited, partly censored screen must **not** be described as an all-archive null.

## Fixed protocol before downloading data

- **Dataset:** the published, fixed-release 4XMM-DR14 EPIC detection catalogue (the full detection FITS, not the slim unique-source table); exact download locations, retrieval timestamps, HTTP status, bytes and SHA-256 hashes will be written to `outputs/receipts.json` by the Actions runner. No moving DR15/DR16 endpoints.
- **Selection:** record the complete catalogue/observation count and a deterministic ordered screening list before inspecting light curves. Prefer soft detections, nonstellar galaxy nuclei, long exposures, adequate counts, and visits that can contain at least two flares. Explicitly record any limits on catalogue volume, remote cross-matches, time-series availability, and API rate/coverage.
- **Temporal tests:** require >=2 well-separated, high-S/N, soft source flares; compare source signal to scaled background, invalid time bins, and pile-up warnings. Report recurrence, energy dependence, competing variability and selection bias; never treat a variability catalogue flag alone as QPE evidence.
- **Controls:** initial positional pilot checks GSN 069, RX J1301.9+2747, eRO-QPE1–3 and AT2019qiz; eRO-QPE4 and Ansky remain pending for position verification. Catalogue presence is not flare recovery.
- **Vetting:** cross-match against galaxy centers (Legacy Surveys, SDSS, 2MASS; exclude Gaia stellar counterparts), then literature/ATel/TNS and eROSITA/Swift/Chandra epochs on any serious candidate. These are **mandatory before** announcing a candidate; unavailable checks remain pending, not passed.
- **Calibration:** inject synthetic recurrent flares into actual cleaned light curves if enough data exist; present recovery fractions, amplitude/period bins, false positives from off-nuclear/stellar and background controls. No claimed calibrated null without defined denominator and injections.
- **Freeze:** `frozen_selection.json` is written before temporal outcomes. A capped first-pass sample of eight ranked detections plus available control detections (at most twelve source products) tests feasibility, not the whole eligible population. All published result tables and checks are deterministic from scripts, release and pinned runtime dependencies. Result outputs are generated by one push-triggered, path-filtered GitHub Actions job, not on every repository PR.

## Execution

Single network-enabled analysis job: `.github/workflows/xmm-qpe-dr14.yml`; script: `search.py`. It runs on pushes to this branch affecting this result folder, except generated files under `outputs/`. The Actions runner batches all outputs into one follow-up commit. The job does not run for repository-wide pull requests.
