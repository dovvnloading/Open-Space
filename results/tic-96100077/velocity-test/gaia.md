## Retrieve and identify

Run from this directory with Python, NumPy and Astropy. The first command records the TAP queries, source identifiers, DataLink responses and product hashes in a new output directory. The second scores the archived data and emits an explicit absence result on pre-release input. The example uses the clock implied by the draft's field label. Check the final release time convention before interpreting the output.

```sh
python gaia_access.py /tmp/tic-96100077-dr4
python gaia_holdout.py /tmp/tic-96100077-dr4/access.json --clock barycentric
```

## Epochs, velocities and uncertainty

The DR3 observing interval ended at OBMT 5230.0880 six-hour spacecraft revolutions (May 28, 2017, approximately 08:45 UTC). The scorer decodes the onboard clock from the integer transit identifier as documented in §17.2. Only visits strictly after that boundary enter. This separates newly observed transits even if a processing release revises the earlier velocities. Those observations still share the spacecraft and aspects of its calibration. [Gaia Collaboration, EDR3 survey properties, §2](https://doi.org/10.1051/0004-6361/202039657) · [DR3 observing interval](https://www.cosmos.esa.int/web/gaia/dr3)

The draft labels `obs_time_rv` in days of BJD(TCB) minus 2455197.5. Its description of `obs_time_bary_corr` also instructs readers to add the latter to transform spacecraft arrival times to barycentric arrival times. For a barycentric epoch, use the `barycentric` setting. For a spacecraft epoch expressed in the same coordinate timescale, use `--clock spacecraft` to add the recorded light-time in nanoseconds exactly once. Compare the results if the final documentation retains the ambiguity. Velocities in `radial_velocity` are already in the Solar System barycentric frame in km/s, redshift positive. Retain the directly reported velocity. The parser rejects mixed source IDs, duplicate transit IDs and an inconsistent time origin. It counts archive-invalid rows, missing values and nonpositive uncertainty separately from the genuinely scored visits.

The primary comparison predicts every new single-lined velocity using the DR3 period, phase, eccentricity, orientation, amplitude and systemic velocity, all frozen. The comparator is a constant velocity set to the weighted mean of the new visits. Positive `chisq_flat_minus_fixed` favors the frozen model. The constant uses one fitted parameter. The number is a descriptive improvement in weighted squared prediction error. Report both RMS errors, the number of visits, largest gap in outer phase, predicted velocity range and typical measurement uncertainty. When the observed phases all have similar predicted velocities, the comparison offers little leverage. A separately reported free slope uses a fitted zero point and gauges whether the changes have the predicted sign and amplitude. Its formal uncertainty conditions on the nominal orbit and individual velocity errors.

The scorer reports results for all archive-valid transits and separately for those documented free of processing flags for deblending or reblending (bits 55 and 56). Its additional covariance-weighted residual sum uses the same 4,096 joint orbital draws at every visit, plus diagonal measurement errors. Template switches, unmodeled calibration correlations, and blending can still cause disagreement. An orbital match would independently extend the RV tracer's timeline.
