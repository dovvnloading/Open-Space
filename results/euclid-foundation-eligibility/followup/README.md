# Visit provenance follow-up

The three earliest lexical IDs in the first inventory were frozen before retrieving layering files. Their per-detector layering tables contain, at the fixed coordinate, respectively 5, 4 and 6 calibrated image identifiers, all pairwise disjoint. MJD ranges are 60544.949–60544.984, 60673.297–60673.332 and 60708.195–60708.230. The source table stores MJD as float32, so its resolution is roughly 5.6 minutes; exact exposure times need higher-precision metadata. The containment test is a planar point-in-polygon test on the supplied radian detector corners; it establishes center coverage only. `layers.py` regenerates `layers-summary.json` from the original FITS tables. Consult the associated SIA response for the complete product URLs: the `DETECTOR-LAYERING-VIS` row with the same observation ID is the source for each table.

The first two visits are development data; the last remains a holdout. Science, RMS and flag image cutout requests for the two development mosaics returned HTTP 400 with `Invalid request. Unexpected query parameters were found.` for both archive host variants and after removing the gzip option. The exact URLs and error response bodies are deposited. A fallback read small sections via FITS HTTP range requests and stored the six resulting images in the campaign directory, not this repository. Their parent URLs and sectioning procedure are in `extract_cutouts.py`. The archive provides RMS rather than inverse variance; no scientific photometry has been inferred.

A selection rule frozen in `PRECOMMIT.md` yielded zero qualifying local maxima within the first 30-arcsecond development cutout. This is a failure to form the prescribed comparison population, not evidence of a source-free field. In particular the all-zero flag requirement has not been calibrated against the release flag definitions. The later visit has not been opened for screening. A larger predeclared region, explicit flag interpretation, background and PSF treatment, and a separately frozen variability threshold remain required before a pilot can report an astrophysical sensitivity or discovery.
