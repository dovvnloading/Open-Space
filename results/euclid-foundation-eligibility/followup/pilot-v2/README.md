# Two-visit development pilot

In a frozen 60-arcsecond region, the first visit yielded 246 local maxima above the defined pixel threshold, of which 30 passed the frozen center, separation and aperture mask criteria. Three of those had usable apertures and positive background-subtracted flux in both development visits. None of the three had the ten shape- and magnitude-matched controls required for a variability test. The empirical null scatter, detection sensitivity and number of true variables are therefore **not determined**. Zero threshold crossings here is a coverage result, not a statistical upper limit on variable sources. The independently exposed third visit remains unopened.

The script and selection were committed before the comparison at revision `5afdaea`. `PRECOMMIT.md` records its rules. Development science, RMS and flag arrays, cut as 600 by 600 pixels at 0.1 arcsecond per pixel, are deposited in `development-cutouts.zip`; `cutout-hashes.json` records individual bytes. They were obtained by HTTP range access to the parent URLs in `../inputs/cutout-requests.json`, using the fixed coordinate and WCS. All six have matching WCS reference coordinates and pixel origin, and science headers report a VIS zeropoint of 24.5. The original disjoint input exposure sets and approximate dates are in `../layers-summary.json`. The locally constructed cutouts are not independent observations.

The all-zero mask used in the earlier pilot was overly restrictive. The revised rule allows VIS flag bits 18 and 24, and rejects other flags. The [VIS flag reference](https://euclid.esac.esa.int/msp/dpdd/v1.1/_downloads/853cef7b4793c838c2ade9538bd55392/VIS_Flags.pdf) identifies those as STARSIGNAL and OBJECTS, respectively; [MER product documentation](https://euclid.esac.esa.int/dr/q1/dpdd/merdpd/dpcards/mer_bksmosaic.html) discusses the propagation and band-dependent interpretation of flags. This selection is deliberately conservative; a rejection does not itself show a corrupted source measurement.

A post-run diagnostic found that 25 of the 30 selected first-visit centers fail the second-visit all-good-aperture condition. The remaining five pass that mask condition; only three yield positive flux in both visits. This diagnostic is exploratory and is not a basis for silently changing the rule. Differences in seeing, galaxy substructure, flag propagation, masks, local background and correlated pixels can alter the inferred flux. The three-object median flux ratio is recorded by the script only as a computational intermediate; it is not a credible photometric calibration. No blank-sky calibration or PSF matching was achieved because the comparison population is inadequate. A new, separately frozen field or flag study is needed before a variability search.

To replay offline, unpack `development-cutouts.zip` into a directory and run the committed script with that directory as `--cache` and a separate output directory as `--output`. It requires Astropy, NumPy and SciPy. Compare its output with `summary.json` and `objects.csv` here. The frozen script uses only the two development IDs; it does not load the holdout.
