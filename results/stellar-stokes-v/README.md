# Circularly polarised radio emission from stars and planet hosts

No new detection has been validated. This draft records the search as the survey products, samples and controls are verified.

## Search design

The observing unit is a star or substellar system in one radio pointing at one epoch. Use Gaia DR3 within 50 pc, a separate confirmed-planet host census without a distance cut, and published nearby ultracool dwarfs. Propagate astrometry to the observation. Measure signed Stokes V and co-located I, compare equal-area offset positions, and retain target records without a usable observation. Per-host limits require local V sensitivity and coverage. Distinguish published radio counterparts, repeat observations, stellar activity and orbital phase evidence.

## Completed

Read the repository's discovery criteria and existing pulsar identity, WISE J0458+6434AB and LoDeSS reports. The WISE work used visit-integrated VLASS Stokes I and is an existing candidate. No repeat claim for that system is intended.
