# Euclid DR1-Foundation Wide: control-first quasar reselection

**Claim: the 3/24 baseline failure was a selection-definition problem, not evidence of missing z>7 quasars.** An exact 35-source-partition ETag-verified audit recovered all **24 catalogue-matched known z>6.5 quasars and 14 labelled dwarfs**, and independently reproduced the original strict **3/24**. Of the known quasars, **20/24** fail the original Y−J≥0.40 colour criterion and **10/24** fail the |VIS-aperture-S/N|<2 criterion (nonexclusive); 2 have nonzero J/H flags, 2 VIS_DET=1, 3 ellipticity≥0.30. The borrowed narrow NISP MUMAX_MINUS_MAG cut kept **1/24**. These are exact catalogue matches, not sky-coverage completeness.

**Frozen v1 relaxed *eligibility* screen (not a validated quasar classifier):** from the original publisher source rows, J flux >0.65, J S/N≥6, H S/N≥4, |VIS aperture S/N|<7, Y−J measured (or 2σ lower limit for nonpositive Y)≥0, −0.20≤J−H≤0.48, ellipticity<0.40, −1.45≤NISP MUMAX_MINUS_MAG≤−0.75, SPURIOUS_PROB<0.7 or missing. VIS_DET and nonzero J/H flags are recorded and penalized, not hard-vetoed. The operator set was tuned **on those same 24+14 matched labels**: apparent matched-quasar recovery **21/24 (87.5%)**, while retaining **4/14 known dwarfs (28.6%)**. Three remaining losses: J052209.82−512709.2 (pathological J−H≈−1.41), J091639.93+683652.9 (VIS S/N≈16.3 and unusual MUMAX), J024401.02−500853.74 (MUMAX≈−3.06). See [frozen machine selection](freeze.json), [full per-object failure audit](output/control_audit.json) and [calibration with Wilson uncertainty](output/calibration.json).

**Crucial calibration limitation:** 21/24 is a *resubstitution measurement conditional on having an MER catalogue match*, not a held-out selection function, imaging-area completeness, quasar posterior, or contamination-free candidate yield; 4/14 dwarfs is not a field purity estimate. The other **96** frozen known quasars have no 3-arcsec catalogue match and unknown image coverage. A full-sky/flux completeness calibration requires injection/recovery, exact per-band coverage and a representative holdout. The luminosity function's ~8–19 z>7 quasars in a *hypothetical complete* 1,900 deg² cannot be equated with this screen.

## Source re-selection and proof gates

The old 462,500 strict-selected JSONL rows alone cannot produce a complete relaxed-cut re-selection. The [new streaming selection](reselect.py) therefore rereads **all 768 original ETag-identified publisher HATS Parquet leaves**, in 32 source-checkpoint batches of 24, checking **all 888,152,165 original catalogue rows**. It records exact global eligible counts, and deterministic local top 200 objects per partition (preserving the global top 200). Every source batch is hashed, committed and audited by a separate [referee replay](referee.py). Generated outputs do not trigger the sole networked, path-filtered push job.

Full-source counts and named new candidates are **pending the new source rescan**; prior 478 morphology-ranked objects are not presented as a new top list. Actual FITS science pixels are attempted with public IRSA SIA metadata and [S3 range-backed FITS reads](pixel_review.py), following the [IRSA Euclid cloud-access tutorial](https://caltech-ipac.github.io/irsa-tutorials/euclid-cloud-access/), instead of the unsupported IBE \`?center...\` query string that returned HTTP 400 in PR #208. A science-pixel preview is not a per-exposure persistence/ghost/blend clearance. CatWISE/unWISE catalogue colours and motion are neither forced-flux nondetections nor proof of non-stellar origin; a failed spectrum/literature query is not a negative result.

**Current label: measured, inconclusive control-selection analysis.** A ranked photometric list is **not a discovery**. **No new spectroscopically confirmed z>7 quasar** has been established by this work. This does not belong in [remarkable findings](../../docs/REMARKABLE_FINDINGS.md).

Data: Euclid ESA DR1-Foundation Wide Survey, IRSA public MER catalogues; [previous complete HATS screen](../euclid-dr1-wide-highz-vetting/README.md), merged PR #208.
