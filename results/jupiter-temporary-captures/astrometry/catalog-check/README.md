# DECam archival catalog check

The CADC Solar System Object Image Search returned 47 distinct DECam exposure times with an `_ooi` science image in 2014, 2017 and 2018. These years give a positive control and two possible additional apparitions within the time range of NOIRLab Source Catalog DR2. W84 topocentric predictions come from the fit to the original 15 MPC positions. Its input positions are fixed for this check. The exposure midpoint is the CADC value. The preexisting calculated CADC sky location in each row serves as a tangent-plane origin for computing the model prediction.

The catalog has five centroids within 0.89 arcsec on April 23, 2014, corresponding to the five original MPC positions. Across the other 42 exposure times, the nearest returned measurement is 2.94 arcsec away. Three successive April 26, 2014 positions identify the same stationary NSC object (116274_8070), and the same is true for the closest group of September 18, 2017 detections (101643_1849). This check supplies no additional astrometric epoch. A footprint can cover a chip gap or an unprocessed image. Empty responses also occur for sources below the catalog threshold.

Each original NSC query searched for matching camera, date, time, filter and selected processing versions within a box extending 0.003° in each coordinate from its center. The exposure table retains those search centers in `query_ra` and `query_dec`. The `pred_ra` and `pred_dec` columns give the final orbit predictions used to measure the separations. The largest shift from an original search center to a final prediction is 0.0064 arcsec, compared with a query half-width of 10.8 arcsec in each coordinate. The combined 23 rows retain their NSC measurement and object IDs. The exposure table includes empty searches. NSC measures the 2014 positive controls from the same exposures as the MPC measurements. Image-level aperture limits and injection completeness were not measured.

Run `python replay.py` in this directory for the per-exposure distances. `--kernel /path/to/de440s.bsp` independently checks the predictions against the orbital fit. `--live` replays the archived query URLs with the original search bounds. The query URLs and hashes in [sources.json](sources.json) describe the original response bytes. Cached data are in [exposures.csv](exposures.csv) and [catalog.csv](catalog.csv).
