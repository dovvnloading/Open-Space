# Independent archive search, 2026-11-15

This branch starts from main and searches outside the repository’s near-Earth recovery and M51 ULX work. The initial scope includes radio transient propagation, pulsar observations, and independent astronomical geometry. We will retain source identifiers, selection boundaries, failures relevant to the reported result, and a replayable numerical test for any claim. A catalog coincidence alone is a lead. A previously published identification will be credited to its discoverers.
