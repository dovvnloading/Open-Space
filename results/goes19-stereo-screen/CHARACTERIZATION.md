# Frozen native-row development characterization

Only six ordered GOES-19 files from 2026-11-16 00:00:00–00:02:00 UTC are eligible. Each row is keyed by file SHA-256 and native row index; source IDs and parent IDs are file-scoped. All rows, including those outside the two-minute window, degraded/unknown quality and invalid positions, are retained. No cross-file deduplication or inference of unique physical events is made. Counts for time, QC and position are overlapping attrition categories; file presence is not a live-time or completeness guarantee.

HDF5 signed storage with _Unsigned=true is reinterpreted at original width; time values use each file's declared scale and offset and origin (which must equal the expected 20-second file start). A present _FillValue is excluded before interpreting data. Group quality 0 is good, 1/3/5 degraded, and other values or fill are reported unknown, never silently dropped. Lat/lon require finite and valid geographic bounds. Source latitude and longitude are product-reported centroids, not reconstructed physical heights. Uncertainty, geolocation/navigation, acquisition completeness and instrument response are not certified. No candidate selection, ranking, altitude, p-value, nondetection or population statement is produced. Exact D: paths, raw hashes, code/runtime, phase, output and separate authorization digest are required before data reads; GOES-18 is never opened. After source access, any selection design is retrospective; validation remains sealed pending a separately frozen prediction.
