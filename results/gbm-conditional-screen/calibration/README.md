# Retrospective GBM null-model stress test

This is a **synthetic-only failure analysis**, developed after the two-burst exploratory light curves and Fourier arrays were inspected. The two original triggers share their physical source and clock between detectors. No target events were read for this work, no new target was accessed, and this is not blind validation or an astrophysical false-positive rate.

The earlier [20-case pulse ensemble](evidence/earlier-ensemble.json) gave 13/20 cases at the Monte Carlo floor of 0.05 using only 19 bootstrap surrogates each. That estimate is restricted to the artificial generator (approximate 95% Wilson interval 43–82% for the binary crossing frequency) and each p-value has a very coarse simulation floor. The earlier 0/19 single case was a warning, not a distribution-level measurement; its three smoothing choices were correlated. An even earlier count/rate normalization bug was corrected before this work and remains recorded in the parent protocol history.

This independent synthetic ensemble tests a different proposal. For each synthetic burst, generate random aperiodic Gaussian pulses and one common AR(1) red-noise realization; each detector has its own Poisson arrival noise and nominal nonparalyzable 2.6 μs deadtime, a different response scale and small smooth response drift. Refit a nine-bin moving-average common envelope to both detectors together, and take the maximum of the minimum detector power over the fixed seven 4-second windows and 109 frequencies. The training, validation, alternate and injection ensembles use separate deterministic random seeds. This is a prospective software stress test of that synthetic model family, not an event fit or a physical QPO measurement.

| Artificial sample | Crossings of threshold set by 100 training cases |
| --- | ---: |
| 100 independent same-family aperiodic cases | 10 |
| 100 independent narrower-pulse aperiodic cases | 100 |
| 100 cases with injected 10 Hz, 20% modulation | 100 |

The 95th percentile training threshold is 11.0407168. Approximate 95% Wilson intervals for the held-out proportions are 5.5–17.4% and 96.3–100% for 10/100 and 100/100 respectively; these omit training-threshold and model uncertainty. The narrow aperiodic family and the injected family are not discriminated by this threshold. The result is a strong failure for that explicit synthetic alternative, not evidence that real bursts share its pulse distribution. In-sample smoothing can absorb or create power; envelope fit uncertainty, PSD family, nonstationarity and spectral evolution remain major issues. The simulator's simple relative response cannot represent energy-dependent/time-dependent response or spacecraft obstruction. It omits overflow-specific deadtime, saturation/pileup, GTI gaps and timing glitches, so it is not a full GBM calibration. Official [GBM caveats](https://fermi.gsfc.nasa.gov/ssc/data/analysis/GBM_caveats.html) and [instrument description](https://doi.org/10.1088/0004-637X/702/1/791) identify these concerns. No real-data p-value or physical inference is supported.

Run `python results/gbm-conditional-screen/calibration/test_calibration.py` for lightweight deterministic checks; full 400-case simulation takes longer. The original executed file retains its original path assumption; the adjacent calibration.py adjusts only that import path for this consolidated tree. Evidence scripts retain their original D: paths. Synthetic performance is not an empirical-background or instrument validation.

## Future held-out cohort proposal — not acquired

Only after root review and a defensible, independently validated null exists: snapshot every NASA GBM trigger directory whose UTC trigger date lies in [2026-11-01, 2026-11-08), retaining all missing summaries as unknown, and apply the same published-summary cuts 5≤T90≤60 s and 1024 ms 10–1000 keV peak flux ≥5 photons cm−2 s−1. Freeze the complete archive snapshot, inclusions/exclusions/unknowns, source localization versions, detector geometry and quality/GTI gates before opening those new TTE events. Predeclare all eligible bursts, non-overlapping 4 s windows and 5–32 Hz 0.25 Hz grid, count trials across every burst/window/frequency, and preserve coverage failures. A detector pair is selected from localization/attitude/response only, without oscillation strength. This cohort is a proposal, not yet enumerated, acquired or analyzed. A later genuinely held-out assessment cannot validate the already-inspected October data blindly, and separately observed detectors still share source and clock. Synthetic false-positive controls and real off-source background checks would not by themselves prove the burst red-noise null.
