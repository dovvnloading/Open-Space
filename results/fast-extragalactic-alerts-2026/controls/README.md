## Known-source checks

Six targeted R-band observations of **GRB 261113A** contained ten eligible pairs on November 13. Nine passed the frozen photometric thresholds. In the most significant pair the afterglow faded from 19.04 ± 0.02 to 19.75 ± 0.05 Vega mag over 1.731 hours, or **9.84 ± 0.75 mag/day** (13.18σ). Both observations used the same telescope and filter. SVOM detected the prompt burst, and VLT measured z = 3.580. These observations test the magnitude cuts on a real in-window event. Targeted follow-up has a different cadence from the public alert streams. The January–October ZTF observations above are external controls acquired by object ID, excluded from the November blind sample. Epoch counts are unique positive-difference visits at S/N ≥ 5, approximated as `(2.5 / ln(10)) / sigma_mag`. When the time and filter match exactly, retain the lowest-error measurement. Test **all** same-instrument, same-band pairs with 0.02 ≤ Δt ≤ 1.0 days, |Δm| ≥ 0.30 mag, |Δm|/Δt > 1 mag/day and |Δm|/hypot(σ₁,σ₂) ≥ 3. These counts isolate the slope cut. They omit downstream context, artefact and completeness cuts. Multiple passing pairs from one object refer to the same source.

For a comparison specific to the orphan interpretation, GOTO announced **AT 2026jpw** in April. Its L-band discovery and second epoch imply a fade of about 3.6 mag/day over 4.06 hours. The discovery group found no underlying PS1 or SDSS source. Einstein Probe subsequently detected an X-ray source in targeted follow-up and AMI-LA detected radio emission. A mandatory visible-host cut can exclude sources like this one. [Discovery](https://gcn.nasa.gov/circulars/44301) · [X-rays](https://gcn.nasa.gov/circulars/44305) · [Radio](https://gcn.nasa.gov/circulars/44379)

Run `python control_photometry.py` here for the archived numerical results. `--fetch` rebuilds the measurements from ALeRCE and the numerical table in GCN 46263 and replaces the local receipts. The difference-flux measurements for ZTF use uncorrected `magpsf` and `sigmapsf`. The archive records the exact UTC download times, URL, byte counts and SHA-256 checksums of all HTTP bodies in `query_receipts.json`. `photometry.csv` retains the epochs used, including ZTF candidate identifiers. Alert services may return longer histories on later runs.
