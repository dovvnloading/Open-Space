# Radio pulsar identity screen

Question recorded 2026-11-15 before ranking. Do nominally distinct pulsar entries describe the same periodic emitter? Cross-survey rediscoveries can retain coarse discovery positions. The observing unit is a pair of named entries. Screen available periods, dispersion measures and sky positions, including low-integer harmonic ratios. Use near-sky mismatches and displaced catalogs as controls. Vet hits against discovery/timing papers, beam sizes, epoch differences, binarity, provenance and acknowledged aliases. Report what each contributing survey actually measured. A pair of independent precise inconsistent positions or incompatible barycentric periods can falsify the identity. Preserve subthreshold and already-reported cases separately from plausible new identifications.
