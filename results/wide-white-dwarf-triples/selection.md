# Source identity in resolved white dwarf triples

This investigation asks whether the two identifiers printed for each resolved pair in Heintz et al. (2022), Table A1, designate the two stars actually described by its astrometry and photometry. The unit is a published pair row. Count all rows before selecting examples and retain rows that agree as controls. For an ambiguous identifier, test both components against positions, angular separation and magnitudes in an independent catalog service. If those constraints leave more than one match, retain the ambiguity.

A corrected source association can change which stars have spectra or atmospheric classifications. Inferring that a star has atmospheric metals requires evidence belonging to that particular component. Check the authors’ versions and published corrections before claiming an original identification. This checkpoint records an identity test in progress.
