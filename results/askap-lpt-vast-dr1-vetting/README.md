# VAST DR1: native-image and counterpart follow-up for 60 radio leads

**Claim first: PR #200 finds no validated long-period transient.** This prospective follow-up vets its 14 bright-detection/quiet-forced-flux patterns first, then all 60 selected sources (693 epoch measurements) using primary publicly released source FITS cubes and catalogue crossmatches. Results cannot be claimed before the Actions job runs and its independent consistency referee passes.

The native source cubes come from the [CSIRO DR1 release](https://doi.org/10.25919/nh9d-t846); retrieval uses the authors' [public source-ID dictionary](https://github.com/IrisdeRuiter/VAST_Extragalactic_DR1). The upstream Git blob is pinned; its pickle is scanned for literal strings, NEVER unpickled/executed. For each original epoch the runner links the FITS extension timestamp to the measurement within 120 seconds, computes center peak versus local MAD noise, flags edge/bright-neighbor/negative-sidelobe risks, and saves a montage. These are quantitative diagnostic flags, NOT independent proof of real variability or artefact rejection. Pixel rows lacking a verified match are explicitly missing. FITS download URLs and SHA-256s are retained.

The counterpart pass queries VizieR's published RACS-low/mid/high Stokes-I component surveys, Gaia DR3, Legacy DR10 photometric-redshift subset, unWISE, Pan-STARRS, eRASS1 and Swift 2SXPS; each individual response is recorded. The non-simultaneous RACS spectral slope, when available, is NOT a physical contemporaneous spectral index measurement. DR10 redshift-subset nonmatches are not optical non-detections. X-ray catalog nonmatches are not flux limits without exposure coverage.

**Critical polarisation limitation:** the VAST source cubes carry Stokes I, not Stokes V. RACS-low2 and VAST AS207 public Stokes V requires access to separately staged CASDA images or catalogues and local leakage validation ([RACS-low2 reference](https://doi.org/10.1017/pasa.2026.10225)). Until measured, ALL source Stokes V states remain not_measured and there is no validated polarised, counterpart-free compact source. There is no seconds-scale survey time series among these monthly sparse epoch samples. Accordingly neither periodicity nor a new LPT is asserted; any surviving candidate would require those data and a source-specific literature/ATel review.

The [single push-triggered job](../../.github/workflows/askap-lpt-vast-dr1-vetting.yml) runs from this branch, excludes generated output paths to prevent loops, and commits small evidence tables and montage files in batches. See output/classifications.csv (60 sources), output/epoch_image_audit.csv (693 rows), response receipts, image hashes and output/referee.json. No [REMARKABLE] marker is justified by incomplete vetting.
