# Fermi weekly-fit audit

Across 1,415 DR2 blazars and blazar candidates the repository returned 1,325,903 weekly bins before the cutoff. Of these, 68,247 passed the quality cuts. Among 612 sources with at least ten qualifying bins, 304 had a flare. Grouping adjacent selected weeks yields 1,468 episodes, including 232 with peaks from January 2024 onward. The last available bin midpoint per source ranged from 2026-10-23 to 2026-11-06 UTC. All 1,415 source requests ultimately succeeded.

The 29 compressed files in `all_fit_inputs/` preserve the four NASA arrays needed to audit every weekly fit, including upper-limit-only and rejected bins. For each source the first `met_delta` is the bin midpoint in MET, and remaining entries give successive differences in seconds. The `ts` and `convergence` arrays use the same index. Each `detected_at` is the zero-based parent bin index for the corresponding `flux`, `lower` and `upper` values. The arrays retain the values the LCR API returned without rounding. Other ancillary fields and upper-limit magnitudes are absent.

Run `python audit_lcr.py` from this directory to reconstruct the four arrays and recompute the bin-quality decisions against the frozen valid-bin shards. Run `python freeze_lcr.py` to reproduce the peak table from those shards. On 2026-11-17 the full fit audit matched all bin counts and all 68,247 individual qualifying tuples, and the offline peak replay reproduced the frozen CSV byte-for-byte. `FIT_SHA256SUMS` fingerprints the compressed shards, source receipts, and derived tables. To recreate the full-fit input package from freshly retrieved NASA responses, use `python audit_lcr.py --cache CACHE`.
