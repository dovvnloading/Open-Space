# Archival extension fixed before any historical discovery crossmatch

The first registration restricted discovery EM epochs to 2024 onward. The LCR and corrected FLAIRES releases contain older, independently selected flares. This companion search tests the earlier epochs without changing the original search. At registration the modern optical, EP-only, gamma and MIR screens have been viewed, and the four named historical validation sources have been examined. No other archival sky-time pair has been inspected. Treat the two epochs as separate analyses, and charge both to any source claim.

Use the same gamma and primary published MIR source definitions, masks, windows, alert-count and inverse-area statistics. Use EM epochs strictly before 2024-01-01 UTC, including every available mission year. Use only complete active, disambiguated IceCat-1 V4 events with calibrated 90% map products, substituting published IceCat-2 polygons wherever released for those events. Remove explicitly vetoed or superseded event IDs. Record any known removals without a public ID crosswalk. Include later active GCN tracks if the registered time window connects a historical EM epoch to their event date. Use native geometry, not RA/Dec extrema. If parts of the older catalogue are unavailable, report the tested cohort and coverage. Mask all four control sources by verified alias or independently measured position (within 5 arcsec for counterpart catalogue centroids). Do not add the 2MRS supplement to this hypothesis family.

Repeat 9,999 RA and time trials using seeds 20261119 and 20261120, with the original year/quarter/tier time strata. Run the same trials across both archival families. Apply a factor of 12 to the unadjusted tails for any claim across both epochs (eight originally registered modern tests plus four archival tests). If a stratum or a null statistic is invariant, report it. Literature/GCN/ATel and source light-curve checks apply to every previously unreported native pair. The historic catalogue changed between releases. Report which reconstruction supports each pair and avoid assigning a significance to an individual source from a population count.
