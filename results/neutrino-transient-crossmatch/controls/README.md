# Historical control replay

The original optical search returns the three reported matches when rerun on the full 43-alert by 63-flare cohort. The tagged author code applies asymmetric GCN RA/Dec boxes, optical and MIR detection durations, and a 0–365 day post-peak cut. The UTC date at midnight reproduces their code's event time. `historical_optical_pairs.csv` reports reconstructed positions and observer-frame delays from the software inputs. The peak delays can differ from printed summary tables that use other epoch choices or conventions. This reproduction validates source identity and original selection. [Original software v1.0](https://github.com/sjoertvv/HelloLancel/tree/91cab012adad9dbc34de6fa5d32a61f457193da3) · [Published analysis](https://doi.org/10.1093/mnras/stae610)

The radio position of TXS 0506+056 is 0.076° from the original revised IC170922A center. The nearest weekly LCR bin lies 0.371 d before the neutrino and has flux 2.91 times the qualifying-bin median. The nearest qualifying flare peak is 2017-09-15 11:59:56 UTC, 7.371 d before the neutrino. The registered joint gamma-ray test therefore misses this historical flare. Fermi's contemporaneous high-state report and the geometric control use different criteria. The 2017 fit is available in the frozen weekly curve. [IceCube GCN 21916](https://gcn.nasa.gov/circulars/21916) · [Fermi ATel 10791](https://www.astronomerstelegram.org/?read=10791) · [Radio coordinates](https://www.astronomerstelegram.org/?read=11419)
