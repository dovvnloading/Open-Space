# C/2025 V1 (Borisov) archival image search

**No new moving-source position is validated in ten pre-arc ZTF science exposures.** All ten contain the predicted position before the first published astrometry on 2025 October 29 UTC. The observations are on October 18 (two exposures), 25 (three), 26 (two), and 27 (three), all in ZTF r. Seven additional exposure footprints coincide with the seven previously measured I41 positions on October 29, 30, 31 and November 1. Local noise in the searched 3.5-pixel apertures gives approximate r-band 5σ aperture magnitudes of 18.48, 18.58, 18.64 and 19.22 respectively. These scales apply to the sampled footprint, adopted ephemeris and aperture. The frozen [archive results](archive-results.json) carry ZTF image identifiers, timestamps and the four corners returned by IRSA. The [query receipts](archive-receipts.json) hash the original Horizons and weekly CSV responses, including windows with only a header. Gzip files contain the responses themselves. The [DECam results and query receipts](decam.json) include exact search parameters, archive-returned counts, and raw-response hashes. The CADC name-based response is kept for provenance. CADC’s local name resolver did not resolve this comet. A second request supplied 497 numerical positions directly and returned HTTP 500. We obtained no usable CADC-wide imaging census. The October 25 and October 27 positive apertures were followed up using fixed-sky controls and independent reductions. October 25 failed the three-exposure test. October 27 gave different peak positions between the clean pipeline differences and the same-night sky subtraction. The published October 29 night, used as a control, gave a 6.26σ difference-image peak within 1 arcsecond of prediction.
