# No new long-period radio transient established — VAST Extragalactic DR1 search

**Claim (provisional, pending the runner):** This is an independent, bounded search for compact, strongly variable 888-MHz ASKAP sources in the *new* public VAST Extragalactic DR1 light-curve release, not a detection of a new minute-to-hour periodic source. **No new long-period transient is claimed.** The source table provides widely separated epochs (typically 10–11) but cannot by itself measure minute-to-hour periodicity.

**Observing unit and freeze.** Pin the published VAST Extragalactic DR1 image table (2,945 accepted images, 276 fields, June 2023–April/May 2025), source table (548,113 entries) and measurement table (6,449,202 rows) from [CSIRO DAP DOI:10.25919/nh9d-t846](https://doi.org/10.25919/nh9d-t846), with checksums, exact source URLs, row counts and field/epoch/SBID rows **before ranking**. Catalogues alone do not certify minute-to-hour pulsing, polarisation, a physical counterpart, or a covered non-detection.

**Frozen scientific screen (before data inspection).** Compact sources only (mean integrated/peak ratio 0.75–1.40); >=8 local-SNR measurement; >=5 temporal measurements and >=2 direct Selavy detections; separated low and high states with a >=5x peak-flux ratio and >=5 mJy high state, or an exceptionally high catalogued variability score (eta_peak >=100 and v_peak >=0.8); exclude sibling-component flags; require >=2 independent above-threshold epochs for the most convincing class. Recheck per-epoch flags, local errors, image IDs and false-forced outliers. These are *screening thresholds*, not a discovery test. Inspect matched controls and radio/optical associations before changing disposition.

**Positive controls.** Crossmatch published long-period objects against the actual image footprints; recovery requires an identifiable detection/epoch, not a coordinate coincidence. Do not equate missing controls with failed sensitivity if DR1 excludes their regions or catalogues. Report sky/time coverage explicitly.

**Completed:** located the peer-reviewed 2026 DR1 paper, verified the data-release column definitions and public DAP DOI; reviewed [docs/REMARKABLE_FINDINGS.md](../../docs/REMARKABLE_FINDINGS.md). The release authors have already classified 117 highly variable sources, including two unidentified sources. Treat every known DR1 variable and known LPT as previously reported, not a new discovery.
