## Scientific approach and gate

**Hypothesis:** at least one single-observation ACT millimetre excess remains not explained by flaring stars, variable AGNs, known Solar System objects, instrumental noise, or the previously published ACT transient sample. Strong alternative: apparent excesses from striping/noise, coverage edges, static sources and reprocessed known events.

The numerical kernel (`mf_core.py`) is a *white-noise* weighted fit on `single_observation - independent_reference`, using `ivar_obs * ivar_ref / (ivar_obs + ivar_ref)`. Its returned source amplitude and SNR are in the native input map units; **it makes no calibrated Jy claim**. It rejects reference maps not explicitly designated leave-one-out, invalid ivar and low-support edge pixels. The real-FITS wrapper (`run_pair.py`) also requires matching WCS and a measured-beam receipt, and labels every SNR peak **uncalibrated**, not a transient. For an ACT result, a real ACT beam/transfer function, correlated scan-noise/null distribution, time/position conventions, and false-discovery trials are indispensable.

**Before any new-event or rate claim, complete**: verify every selected product/release/time/ivar and accessible-sky coverage; choose a truly independent coadd excluding the tested observation; account for correlated noise and beam/transfer functions; recover eligible Naess et al. (2021), Li et al. (2023) and Biermann et al. (2024/2025) published events; sign-inverted maps *plus independent split-map jackknives* and coverage/scan-edge vetoes; inject variable-flux sources across band, epoch, sky position and duration to measure completeness; JPL Horizons moving-object checks; ACT/SPT/Planck static and variable-source exclusions; Gaia and VLASS/RACS; Swift/GCN, TNS and literature counterpart checks; independently inspect **all** survivors. Published ACT detections must be **recovered from these pixels** to count as positive controls; literature counts do not satisfy this gate.

The effective exposure for a flux and duration selection, `E(F, tau) = integral dOmega dt epsilon(F, tau, sky, time)`, is **unknown**. A zero-event 95% Poisson rate upper limit would be `-ln(0.05)/E`, but **no numerical bound may be given until eligible exposure and completeness are validated**, and clustered/correlated trials are handled appropriately.

## Reproducibility

An Actions runner successfully acquired the SQLite catalog and froze all 31,261 rows; compare byte hashes above. The GitHub Actions inventory workflow runs synthetic unit tests and publishes its receipts. To reproduce the eligible dataset from the *same frozen SQLite*:

```bash
python results/act-dr6-mm-transients/freeze_mapcat.py --db mapcat.db --out full.jsonl --receipt full-receipt.json
python results/act-dr6-mm-transients/freeze_scoped.py --manifest full.jsonl --catalog-receipt full-receipt.json --out eligible-act-depth1.jsonl.gz --receipt eligible-receipt.json
python -m pip install numpy scipy
python -m unittest discover -s results/act-dr6-mm-transients -p 'test_*.py' -v
```

Optional bounded product staging: `download_products.py --manifest eligible-act-depth1.jsonl.gz --manifest-sha256 b6a0c020e3b03bc23aac66536ae1b31cb8889cbc3295c1d2acf16f8de3952503 --map-name 'EXACT/FROZEN_NAME' --out /tmp/act-products`. The downloader records downloaded FITS checksums. It does not imply independent coadd subtraction or a transient result.
