# ACT DR6-era depth-1 millimetre transients — frozen inventory and **inconclusive real-pixel field pilot**

**Claim (18 November 2026, US Eastern):** The frozen public ACT depth-1 inventory contains **27,512 rows** across the 90, 150 and 220 GHz channels, 2017–2022. A separately preregistered, **0.30-degree-radius, targeted** PA4/150 GHz September 10–12 2018 ROI search now **read and filtered authentic ACT science/ivar FITS pixels**. Two test maps and seven other-night reference maps had usable pixels. The deliberately provisional **white-noise** screen returned **nine local ≥7 formal-SNR peaks**, but independent split-night nulls have MAD **12.10 formal-SNR units** and both positive and negative extreme tails; thus this is **not a calibrated detection, a measured astrophysical null, or a rate limit**. The published event in the target field was **not validly recovered**. Counterpart vetting is **incomplete**.

**Disposition: INCONCLUSIVE real-pixel engineering/feasibility pilot, not discovery.** No `[REMARKABLE]` tag or addition to `docs/REMARKABLE_FINDINGS.md`. The already-merged inventory PR [#192](https://github.com/dovvnloading/Open-Space/pull/192) remains an inventory-only historical result. This field attempt belongs to [PR #198](https://github.com/dovvnloading/Open-Space/pull/198), not a retroactive edit to #192.

## Statistical interpretation and scientific acceptance gates

The numerical `mf_core.matched_filter` is a diagonal-inverse-variance, single-observation minus independent nightly-reference point-source estimator, **not** a physically calibrated ACT correlated-noise/transfer matched filter. The returned amplitudes remain native map units (assumed but not independently verified μK_CMB), **not Jy**. A formal `SNR_white>=7` is only a screening threshold; given empirical MAD ~12 and abundant signed jackknife tails, it cannot be interpreted as a 7σ astrophysical significance. Positive and sign-inverted peaks and the disjoint-night jackknife show the model's failure, not an astrophysical transient null. Injections into only four supported locations are not a completeness surface.

The following are **still required** for new-event or rate claims: instrument-specific beam/transfer measurement and uncertainty, reliable native map unit validation, empirical source-weighted correlated-noise nulls and trials correction, valid full-FITS byte provenance/masks and repeated/independent-array observation, positive control recovered at native pixel UTC and sky coordinates, explicit full-catalog optical/radio/IR/static-source associations, complete topocentric Horizons moving-object veto including all relevant objects, alert/GCN/TNS adjudication, and flux/duration-dependent efficiency with actual sky-pixel dwell times. **A targeted published-event field is not an unbiased survey denominator.**

The effective exposure `E(F,tau)=int dOmega dt epsilon(F,tau,sky,time)` remains **unknown**; a formal zero-event Poisson 95% limit `-ln(0.05)/E` cannot be supplied. The nominal nine peaks cannot be counted as discoveries or used as a calibrated non-detection sample. This work does **not** satisfy the discovery-level `[REMARKABLE]` bar.

## Reproduction

The job triggers **only on push to** `research/act-dr6-mm-transient-search` touching `run_preregistered_field.py`, `test_preregistered_field.py`, `vet_candidates.py`, `roi-footprint-cache.json`, `PREREGISTRATION.md` or the workflow itself. Output receipts/README changes **do not retrigger** it. The runner reads bounded real science+ivar/mean-time FITS ranges from the SODACAN public bucket and writes `science-pilot-receipt.json` and `candidate-vetting-receipt.json` back to the research branch; a lease guards against stale evidence.

```bash
python -m pip install 'numpy>=2.0' 'scipy>=1.12' 'astropy>=6'
python -m unittest discover -s results/act-dr6-mm-transients -p 'test_*.py' -v
python results/act-dr6-mm-transients/run_preregistered_field.py
python results/act-dr6-mm-transients/vet_candidates.py
```

The actual science steps require network access and can time out on public APIs. A local offline run can exercise synthetic tests but **cannot** reconstruct real observations without the network service. Full staged FITS checksums, where feasible, are a separate `download_products.py` exercise, **not** established by byte-range receipts.

Original inventory reproduction (requires the same pinned `mapcat.db` binary):

```bash
python results/act-dr6-mm-transients/freeze_mapcat.py --db mapcat.db --out full.jsonl --receipt full-receipt.json
python results/act-dr6-mm-transients/freeze_scoped.py --manifest full.jsonl --catalog-receipt full-receipt.json --out eligible-act-depth1.jsonl.gz --receipt eligible-receipt.json
```
