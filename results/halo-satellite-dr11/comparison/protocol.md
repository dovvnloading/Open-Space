# Independent Pan-STARRS1 photometry

Use Pan-STARRS1 DR2 primary stack detections in the two frozen DR11 rectangles. The native PS1 passbands, seeing and classification differ from DR11. Partition each field into 0.5° rectangles, query an enclosing cone for each, and keep only that cell's half-open rectangle. At duplicate object IDs keep the row with the smallest sum of g and r variance. Test independent photometry at published control centres and at any primary detections that pass the frozen threshold. Fixed sampling apertures are 8′ for Boötes I and 6′ for Coma Berenices. For other peaks use the primary detection aperture. Use a same-area-scaled local annulus of 2–3 aperture radii. A comparison aperture crossing the footprint is flagged.

Require 17 ≤ g < 22.5, 16 ≤ r < 22.5, 0 < σg,σr < 0.15 mag, and |iPSF−iKron| < 0.05 with positive i photometry. Measure an on/off count excess separately for the full selection and the PS1 old metal-poor CMD selection. Seek agreement at literature distance moduli for the controls. These are targeted, independent-exposure checks conditional on the primary sample and selected positions. No PS1-only discovery trial or sky-based detection limit is inferred from them.
