# Population model

`parsec.csv` contains initial mass in solar masses, evolutionary label, and DECam absolute AB g and r from the 12 Gyr, initial Z=0.0002 PARSEC v1.2S + COLIBRI model. The published source archive, extraction columns, and original/derived SHA-256 digests are recorded in `receipt.json`. The model is one old metal-poor population. Age, metallicity, unresolved binaries and extra-tidal structure have no fitted spread. [Marigo et al. 2017](https://doi.org/10.3847/1538-4357/835/1/77) · [ugali v1.9.0](https://github.com/DarkEnergySurvey/ugali/releases/tag/v1.9.0)

`search.py` interpolates the pre-helium-flash sequence (label 0 in this particular file, encompassing main sequence, turnoff and RGB) in g. Each source contributes exp[−(observed − model colour)²/(2σ²)], with σ² = 0.05² + σg² + σr². The interpolator assigns zero weight outside its magnitude range. This is a CMD colour-likelihood filter. It gives unit peak weight at each supported magnitude, with no explicit luminosity-function or foreground-CMD reweighting. Gaia and HB stars enter independent follow-up. The photometric errors in g and g−r are correlated, which this filter approximates using colour uncertainty only.

For a circular on-region and its local annulus, let α denote the ratio of on/off pixel counts. The detector ranks `(Σon w − α Σoff w) / sqrt(1 + Σon w² + α² Σoff w²)`. The unit noise floor prevents sparse bins from dominating. The score is a ranking statistic; the empirical family-wise p-value uses paired shuffled maxima across both fields. The null fixes the actual stellar positions, including stellar density around the known controls, and preserves the observed CMD within each ~0.25° sky cell. It tests localized CMD concentration beyond that conditional null. It does not simulate large-scale Galactic structure or offer a universal false-discovery rate. Bright-star masks and variable completeness inside geometrically valid annuli can affect this statistic.

`inject.py` integrates a continuous two-segment Kroupa IMF over the tabulated initial mass interval, with 16 mass subdivisions per isochrone interval. Evolutionary phases with a luminous endpoint carry their IMF weight. Each realization is a Poisson draw from the luminosity function normalized to the **expected** integrated V-band flux. Realized magnitudes fluctuate, especially for sparse systems. The V-band conversion `g − 0.5784 (g−r) − 0.0038` is approximate for DECam. The source filter explicitly omits objects intrinsically >2 mag fainter than the selection. The colour filter omits the post-RGB phases even though they contribute to model light and the injected population. [Kroupa 2001](https://doi.org/10.1046/j.1365-8711.2001.04022.x) · [SDSS transformation](https://www.sdss4.org/dr14/algorithms/sdssUBVRITransform/)

Each realization uses a projected circular Plummer profile. Errors are drawn in flux space using g/r 5σ point-source depths at the nearest catalogue source, plus a 0.01-mag floor. Source points farther than 1.5 arcmin from any catalogue object, or in a nearest-object mask with a flagged survey bit, are discarded. The hard magnitude and error cuts match the search. Detectable, unblended injected stars are assigned stellar morphology. This approximation ignores Tractor deblending and losses from PSF classification or crowding; catalogue-level fractions generally overestimate image-level recovery in those regimes. Six injections per quadrant (24 per field and population bin) use uniformly distributed positions in the geometrically valid 3-arcmin grid, omitting known control centres within ~24 arcmin. The 95% Wilson intervals quantify Monte Carlo sampling uncertainty only. Changes in assumed population, depth model and field choice introduce systematic uncertainties. The spatial table retains separate quadrants (0 = south/west, 1 = north/east).
