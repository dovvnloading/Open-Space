# Resolved Milky Way satellites in Legacy Surveys DR11

**No discovery or survey null has been established.** This draft opens the observing record before source retrieval and ranking. The question is whether an old, metal-poor resolved population in a fixed high-latitude footprint survives the same search that recovers known satellites and synthetic populations.

The primary survey is Legacy Surveys DR11. Gaia DR3 supplies astrometric and RR Lyrae follow-up. Survey overlap is tracked at the exposure level when judging independent evidence. The repository's discovery log requires a validated discovery-level finding. The open-cluster flyby, planet and neutrino campaigns are outside this search.
