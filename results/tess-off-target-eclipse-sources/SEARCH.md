# Independent eclipse-source identification

Compare live TESS Objects of Interest against separately measured Gaia DR3 eclipsing-binary clocks. Require agreement in period and phase, then locate the missing light in independent TESS pixel data. The initial TOI-2541.01 results from sectors 6 and 32 favor an offset Gaia source. Check additional TESS sectors and prior attributions in ExoFOP before interpreting candidate status. This work does not modify any external disposition.

**Outcome of the checks.** A previous published source-localization table already assigns TOI-2541.01 to the offset star. The investigation moved to TOI-3143.01. For this target the SPOC reports already measure an offset. The new result connects the missing TESS light to the independent Gaia eclipse clock of TIC 384244835.
