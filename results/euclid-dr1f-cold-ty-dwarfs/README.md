# Euclid DR1-Foundation: very cool T/Y dwarf VIS-dropout search

**Claim — no novel sub-500 K brown dwarf or colder-than-WISE-0855 source is established by the material in this branch.** A complete 768-partition source screen, epoch-aware known-object controls, CatWISE/unWISE/optical/SIMBAD receipts and an independent receipt replay are required before interpreting a numerical candidate count. All new leads remain *photometric possibilities* until source images, proper motion and spectra are independently checked. This is a distinct Euclid DR1-F analysis, **not** a repetition of the WISE motion-first experiment in [cold-neighbours-motion-selected](../cold-neighbours-motion-selected/README.md).

## Frozen dataset, selection and falsifiers

- Public Euclid **12 November 2026 DR1-Foundation** Wide Survey MER HATS Parquet (IRSA673), 768 HATS partitions / 888,152,165 advertised source rows; frozen partition index SHA-256 `f7940bcaed19b6f67295c5592cc81783d798c0f858062d7293e5e3dfbfa57c2a`. Uses the existing [wide HATS S3 row-group reader](../euclid-dr1-wide-highz-vetting/scan.py) **but a new independent T/Y mask and a separate output dataset**.
- VIS_DET=0, VIS aperture |S/N|<2, J≥6σ, good J/H flags, NISP ellipticity<0.25, spurious probability<0.5 (if finite), Euclid AB Y−J≥0.35 and J−H≤0.15. Y below 2σ uses a conservative Y−J *lower limit*; H below 2σ uses a conservative J−H *upper limit*. Nothing uses the VIS-derived POINT_LIKE_PROB to classify VIS dropouts. Ellipticity alone does **not** validate a stellar PSF.
- The **colder-priority diagnostic** is Y−J≥0.50, J−H≤−0.15 and no >3σ positive ground-optical MER flux. Extremely blue values beyond −1.4 are penalized in ranking rather than assumed to imply cold temperatures. Do not conflate this exploratory diagnostic with the frozen mask.
- Known T6/T7, T8/T9/Y and z>6.5 quasar controls; motion-propagated catalogue locations to approximate Euclid epoch 2024.25 (not tile-specific timing), then 3-arcsec match. A HATS pixel is not proof of observed, high-quality sky; conditional recovery uses only matched catalogue controls.
- Frozen literature sources for identification: [UltracoolSheet v2.1](https://zenodo.org/records/15802304), [Kirkpatrick et al. (2024) 20-pc census](https://exoplanetarchive.ipac.caltech.edu/docs/20pcCensus.html), [Schneider et al. (2026) Backyard Worlds list](https://doi.org/10.3847/1538-3881/ae5b60). SIMBAD mirror queries are fallible, especially with stale astrometry; an unmatched record is **not proven new**.
- CatWISE2020 W1−W2 uses motion-fit *Vega* magnitudes only when both W1 and W2 pass S/N tests; CatWISE motion is propagated from 2015.405 to 2024.25 and must position-match. An unWISE flux ratio is **not** a calibrated Vega colour. Independent Legacy/Pan-STARRS query failures and catalogue emptiness do **not** give optical flux limits.
- Conditional photometric distances, when supported, use published parallax-calibrated M_W2 subtype anchors and their scatter. No Euclid NISP colour is assigned a calibrated temperature or spectral class from an invented relation. Underlying empirical Euclid colours: [Žerjal et al. (2026)](https://doi.org/10.1051/0004-6361/202556980); release catalogue and WISE references: [IRSA Euclid](https://doi.org/10.26131/IRSA673), [CatWISE column definitions](https://irsa.ipac.caltech.edu/data/WISE/CatWISE/gator_docs/catwise_colDescriptions.html).

## Evidence status

The networked processing and full catalogue measurements are **pending** at initial submission. Read the committed [scan status](output/status.json), [full aggregate](output/summary.json), [control recovery](output/controls_recovery.json), [40-object external query receipts](output/external_receipts.json), [final vetting status](output/vetting_status.json) and [independent referee](output/referee.json) when present. Missing files mean the corresponding measurement has *not* been done.

**Discovery gate:** spectral type below ~500 K and novelty need actual multi-band photometry with quality masks, external match against dated literature and an independent epoch or spectrum. No new object can be called colder than WISE 0855 from a dropout colour alone. No `[REMARKABLE]` label or log entry unless that bar survives the referee check.

This analysis uses public Euclid DR1 data from the ESA Euclid mission. See [RUNBOOK.md](RUNBOOK.md) for the branch-scoped execution contract and source/selection fingerprints.
