FASHI 20260037137 has a 1407.2941 MHz emission line. If it is the redshifted 1667 MHz OH line, the predicted redshift is 0.18480. Two DESI targets within 3 arcsec have compatible redshifts. The predicted 1665 MHz line is near 1405.642 MHz. This is a testable candidate pending confirmation of the line identification and a check against earlier work.
