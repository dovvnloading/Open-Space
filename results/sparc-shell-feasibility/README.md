# SPARC shell-mass check

Across 175 SPARC galaxies, 3,391 measured radii and 53,507 within-galaxy radial pairs, no individual pair requires decreasing enclosed spherical halo mass by more than 1.17 formal endpoint standard errors throughout the tested nuisance ranges. In IC 4202 the largest fixed-model discrepancy is 17.53 at 0.77–1.59 kpc. Across that galaxy, even the strongest pair left after the sensitivity test reaches only 0.59. We closed this discovery lead. Gas alone never exceeds the tabulated total circular-speed squared at these radii. [SPARC mass models and references](https://astroweb.case.edu/SPARC/)

For spherical halo mass, compare the inner and outer values of radius times observed speed squared minus radius times the model baryonic speed squared. Positive differences imply mass decreases outward. The code uses signed component squares, including outward model forces, and propagates the reported speed errors independently to first order. The default gas, stellar disk and bulge factors are 1.0, 0.5 and 0.7. For each pair independently minimize its score over factors of 0.8–1.2, 0.2–0.8 and 0.3–1.0. The baryonic contribution scales linearly with distance and with the square of the adopted-to-catalogue inclination sine ratio when expressed in catalogue velocity units. Vary both by two quoted errors, clipping distance to at least 1% of the catalogue value and inclination to 1–90 degrees. This tests individual pairs. A different nuisance choice may minimize each pair, and formal scores exclude covariance and velocity-field systematics.

Download `Rotmod_LTG.zip` and `SPARC_Lelli2016c.mrt` from the [SPARC archive](https://astroweb.case.edu/SPARC/) into one directory. From this folder run `python replay.py /path/to/downloads > reproduced.csv` and compare with `screen.csv`. The script verifies both SHA-256 hashes and uses all radii in the published mass-model ZIP. The protocol was committed before inspecting these inputs. The original rotation-curve sources are listed for each galaxy in the catalogue. [Lelli, McGaugh & Schombert 2016](https://doi.org/10.3847/0004-6256/152/6/157)
