# Magellanic RR Lyrae pulsation transitions

Compare coordinate-matched OGLE-III and OGLE-IV Large and Small Magellanic Cloud RR Lyrae classifications and published periods. The targets are RR Lyrae stars. Prior work in this repository on classical Cepheids uses a different stellar population.

Select transitions between fundamental and overtone, and between single and double radial modes. Combine RRc and RRe in the first pass because the two releases use different subtype conventions. Inspect both releases' photometry at both proposed frequencies, within individual observing seasons where sampling permits. Reject catalog relabeling, harmonics, daily aliases, confusion, and stable two-mode stars that merely cross a catalog selection threshold. Check release remarks and published lists before assigning novelty. The primary alternative is that an apparent transition is caused by cadence or classification. Quantify recovery of the missing mode in each epoch before describing it as absent.

A repository match or literature match is insufficient evidence for a new result. The original photometry, date ranges, fitted amplitudes and falsification checks determine the disposition.
