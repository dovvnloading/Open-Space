# Bright stationary neighbours explain dense near-pole W2 track coincidences

**Two W2-only paths crossed established stationary infrared sources.** These fields produced hundreds to thousands of held-out catalog hits in the moving association tube. Twenty-two half-year centroid bins and 256 native W2 exposures show that the bright sources were already at the late predicted positions years earlier. A fitted dipole on either forecast path falls substantially below the W2 flux attributed to the moving source.

Matches require a clean W2 S/N ≥5 measurement, the criteria of the [single-exposure screen](../widebatch/README.md), and a 2-arcsec matching radius unless another radius is explicitly given. The fixed alternative is centered on an actual field source, so its 2015 coordinate is generally different from the W2 link's 2015 coordinate. The original test that held the proposed object's starting coordinate fixed did not test this alternative.

For each path we first identified where the moving window accumulated late detections, then examined an 8-arcsec radius about that location in pre-2019 data. The strongest pre-2019 density peak in a 1-arcsec aperture determined the fixed position. This uses the late associations to identify the field to examine, but only pre-2019 exposures to locate the fixed source in that field. Before 2019 there were 8,584 and 20,873 centroids within 2 arcsec of the respective fixed positions. Fits to the medians in [22 half-year bins](fixed-centroids.csv) give (−0.0074, −0.0014) and (−0.0011, −0.0009) arcsec/yr in the two tangent-plane directions. The 2-arcsec selection conditions these small slopes. Presence at the same position in the original early and late exposures is the independent pixel check.

Each image test uses 64 January 2014 and 64 December 2023 W2 exposures with frame quality ≥5, chosen by boresight proximity within each date window. The fixed-sky late-minus-early fit uses the linked proper motion and reference coordinates. The residual amplitude at track 2 is positive in both disjoint splits. A fainter variable or moving contribution is not excluded. Track 6's two splits give negative amplitudes. The respective 40-translation MADs are 3.75 and 4.09 DN. The source-window counts or local scatter alone cannot give a false-alarm probability.
