# Held-out final-release NEOWISE detections for the bright wide screen

[summary.csv](summary.csv) contains one row for each literature-unmatched bright target and the published T8 WISE J0857+5604 as a control. It reports counts of actual infrared detections at the propagated coordinates during 2019–2024. Older detections are used only for the trajectory diagnostic in the per-source record. At the control position 120 clean W2 centroids fall within 2 arcsec of the predicted track over 11 held-out visits, compared with two at its fixed 2015 position.

For each target we query a cone of radius `ceil(10 × motion_in_arcsec_per_year + 14)` arcsec in IRSA's final `neowiser_p1bs_psd` single-exposure catalog. Proper motion in RA already includes the cosine of declination. Every exposure epoch is propagated from MJD 57170. We retain raw counts of W2 signal-to-noise ≥3 and ≥5 within 5 arcsec after the cutoff. For the 2-arcsec test we require W2 S/N ≥5, W2 profile-fit reduced chi-square <3, frame quality ≥5, a clean W2 contamination flag and no association with a known solar system object.

Four reference trajectories use the original coordinate with zero motion and with the measured motion rotated by 90, 180 or 270 degrees. An operational follow-up requires at least eight clean matches in four visits and more than twice the maximum count on those four alternatives. The alternatives overlap for slow sources. Counts measure consistency with the proposed track. The pipeline can miss real sources because of blending, low per-exposure sensitivity, a faulty input motion, positive parallax displacements, and the catalog's own source-extraction thresholds. Confused or sparse detections can occur by chance. The counts and correlated rotated tracks provide no calibrated discovery probability or limiting volume.

For sources having ≥6 visits with ≥2 qualifying detections in a 2-arcsec tube and a ≥4-year baseline, a weighted five-parameter diagnostic fit is also saved. It uses visit medians, coordinate MADs with a 0.15-arcsec floor and Earth barycentric parallax factors. The fit's parameter order is east offset, north offset, east motion, north motion and relative parallax. The reference time is MJD 58500. These fits select their input positions using the input proper motion, and their errors condition on the scan calibration and association. They support image triage and cannot alone establish a new object's parallax.

Run `python screen.py --selected ../wide/selected.csv --matches ../catalogues/wide_matches.csv --control` with Astropy, NumPy and pandas. The per-cap record packets indexed in [coverage.json](coverage.json) preserve a JSON object per source. Each record identifies the requested URL, instrument rows, hashes, held-out counts, arcsec-scale track fits where computable, and nominal catalog input values. The per-cap neighbour packets preserve each source’s exact CSV bytes as indexed ASCII text pieces. Each reconstructed CSV contains the quality-selected archived rows within 5 arcsec of any tested track. When assessing raw counts at S/N ≥3 use the original archive response. The raw SHA-256 includes service-generated timestamp metadata; a separate digest covers the returned table without the archive's backslash-prefixed comments. The replay also writes loose per-source files under `retained/`. Running `python package.py --selected ../wide/selected.csv --matches ../catalogues/wide_matches.csv --out .` rebuilds the per-cap packet and checks complete coverage and subset hashes. The `--heldout-mjd` option supports a later data split if the starting catalog uses observations beyond CatWISE2020.
