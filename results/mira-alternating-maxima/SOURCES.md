# Data and attribution

The Swedish Variable Star Observations catalogue by Thomas Karlsson supplies the integer cycle numbers, observed dates and fitted visual peak magnitudes. We read all five constellation indexes on 2026-11-15 and followed their unique star links. The catalogue includes fits to observer data and published maxima. Its timing is tabulated in integer Julian days. Each source page URL, SHA-256 and usable-row count is in `catalog-manifest.csv`. The frozen numerical series uses integer tenths of a magnitude to preserve the catalogue's exact ties. The named-star extracts also retain source labels (SVO or AAVSO). A positive odd-minus-even magnitude means that the even cycle was brighter. [SVO index](https://var.saaf.se/mirainfooc.php) · [Karlsson 2013](https://var.saaf.se/doc/Karlsson-miras.pdf)

We acknowledge the variable-star observations from the AAVSO International Database contributed by observers worldwide. The names in the tables are AAVSO observer codes. The three targeted queries, hashes of the complete returned XML payloads and row counts are in `comparison-aid-sources.csv`. The frozen extracts retain observation IDs, dates, band, magnitude, observer code and validation flag in the targeted windows. For the original comparison, take each visual estimate or instrumental observation within 40 days of each selected cycle's catalogue maximum, then apply the subset requested by each check. Visual and Johnson V are analyzed separately. AAVSO flag T marks a discrepant measurement. A stricter check keeps only flag V (validated), and upper limits are always excluded. An observer split checks susceptibility to an individual observer. The catalogue and the observer reductions can share measurements. The ESA Hipparcos epoch-photometry file contains 105 transits for HIP 66100. The first line is the catalogue header. Transit times are BJD(TT) − 2440000 and the band is Hp. The separate test uses transits with quality integer 0 or 1. Group them by rounded day relative to the nearest catalogue peak within 25 days. The CDS index locates the star's gzip member at zero-based byte range 71420274–71421375 inclusive in `hep.gz`. Decompress this member to recover `hip-66100.dat`, SHA-256 `f9d54a9b38c9e2842b3ce485bd835039dee34f952d63bf18127629df7f342776`. The few-minute difference between barycentric spacecraft timing and catalogue peak dates is negligible compared with the day-wide offsets in this check. ## Selection and synthetic controls

The longest-run ranking uses numeric measured maxima within contiguous cycle segments. Runs break at a missing cycle, a repeated magnitude or a repeated step sign. We also inspected even–odd mean contrasts and sliding-window alternatives before selecting targets for follow-up. `star-runs.csv` includes all 510 star-level outcomes. A run counts peaks, so 25 peaks have 24 alternating steps. Subsequent observer cuts, interval selection and literature checks were exploratory.

The Monte Carlo controls use the observed amplitudes as an empirical distribution for each star. In the block model, choose a starting offset, randomly reorder the blocks including partial end blocks, then assign the values back to the original observed cycle numbers. Here a block contains successive *observed* peaks and can span a missing cycle. Each synthetic survey reruns the same gap and tie rules. In the autoregressive comparison, estimate the adjacent-cycle correlation using normal scores of the measured ranks. Propagate that model across the observed gaps and return the exact measured amplitudes in the order of the generated ranks. Threshold counts range over 15–33 peaks inclusive. The upper-tail rank includes ties and treats every simulated survey as a potential observation. These controls preserve different aspects of the data. None models the complete observation and catalogue-fitting process. The source catalogue reflects decades of monitoring choices and is not volume limited.
