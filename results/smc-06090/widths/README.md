# TESS eclipse-duration test

For each group we measured the full widths at half the flux deficit of two Gaussian profiles with independently fitted centers and a sinusoidal baseline. The reported difference is secondary minus primary, in minutes. In 2025 that difference was +22.3 (conditional 95% bootstrap +0.4 to +42.7) from the central 3x3 aperture. It was +14.7 in the four-pixel and +7.6 in the single-pixel apertures, and +8.1 with direct sky subtraction. All are reductions of the same exposures. These estimates have the sign predicted by the forward geometric model. The size varies with extraction and our 95% bootstrap is conditional on one reduction. The supplementary single-orbit bootstrap in ../physical/tess_widths.json yields a much broader −33 to +92 minutes, including either direction. Earlier durations depend much more strongly on reduction. The width test gives a tentative direction clue only. The folded TESS duration statistic and the model's flux FWHM can differ for non-Gaussian shapes and finite exposures.

measure_widths.py uses the compact orbit-folded pixels in ../joint/inputs and resamples groups of up to three consecutive orbital cycles within each sector. Each bootstrap fits both widths, centers, depths and the baseline again. sky_widths.py uses short per-orbit sky-reduced flux tables already distributed here. With NumPy and SciPy run python measure_widths.py and python sky_widths.py. To re-extract the alternate orbit folds from MAST, run python build_sky_folds.py PATH_TO_FITS. The MAST URLs and science hashes are in ../joint/inputs/tess_inputs.json.
