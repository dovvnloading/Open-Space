# Physical scale and published comparison

Hong et al. (2016) analyzed 90 new SMC systems with apsidal motion. Their search required OGLE-III I < 18.0. OGLE-SMC-ECL-6090 is I = 18.232, outside their selection. Only SMC-ECL-6029 has a shorter sidereal period than the 1.16967 days of our target in their Table 4. Their sample is brightness-, time-baseline- and detection-selected, and other SMC literature also exists. This comparison does not establish a record or priority. The OGLE catalog lists the present target as a detached/non-contact binary. Earlier identifier checks are provided in prior-work.md, with the matched SIMBAD record. [Hong et al. Table 4](https://doi.org/10.1093/mnras/stw955) · [OGLE-III catalog](https://www.astrouw.edu.pl/ogle/ogle3/OIII-CVS/smc/ecl/)

The joint Kepler fit supplies the eccentricity and period for a first post-Newtonian estimate of the general-relativistic part of the apsidal advance. Solving the rate formula for a purely relativistic interpretation requires a total mass on the order of 750 solar masses. That number is a conditional scale, not a measured mass. No spectroscopy constraining the masses was used. Apsidal rotation in ordinary binaries can include tides, stellar rotation and perturbations by an additional body. This calculation does not distinguish those causes. [Giménez 1985](https://ui.adsabs.harvard.edu/abs/1985ApJ...297..405G/abstract)

Run python physical_context.py. Regenerate the numeric comparison subset with --download (requires pdftotext) or --table-text PATH to pdftotext -layout output of the authors' preprint.

## Predictions for withheld Swift observations

uv_prediction.py freezes the full optical/TESS model phase evolution, then scores the 275 accepted Swift measurements using independent yearly normalizations, free ultraviolet eclipse depths, the same two Gaussian widths, a 6% error floor and a common normalization for every timing law. With centers fixed to the optical predictions, the 3.5-arcsecond aperture yields chi-square values of 277.05 (precessing orbit), 276.44 (single trough), 276.18 (cubic) and 303.36 (constant separation). Allowing a constant ultraviolet center offset for each eclipse gives 275.86, 275.25, 275.13 and 282.16 respectively. The optical timing models used no Swift photons. Swift supports changing timing while leaving the precession and one-time dip practically tied. These scores summarize within-sample UV depth/baseline calibration and include the stated photometric noise model; they are not posterior probabilities.
