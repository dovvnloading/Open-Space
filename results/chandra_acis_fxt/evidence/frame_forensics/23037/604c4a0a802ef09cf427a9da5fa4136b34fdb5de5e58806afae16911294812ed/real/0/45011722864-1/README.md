6 peak photons occupy 2 distinct ACIS exposure numbers. Their 6 distinct detector pixels include at most 2 photons on a common CHIPX column and 2 on a common CHIPY row.

The brightest source peak frame contains 5 selected photons. Across 6100 recorded CCD frame keys, 0 of 48800 control aperture–frame pairs reached that count. Eight equal-radius sky apertures lie five aperture radii from the source, spaced every 45 degrees. Varying exposure, detector edges, diffuse emission, crowding and the choice to inspect this trigger limit this descriptive comparison. The original survey controls and selection remain the basis for its false-alarm estimate.

The event table is pipeline-filtered level 2. Rows in the local and full-frame tables precede this audit’s grade, energy and status selection. Events rejected by onboard or level-2 processing and unsent pixel-island data are unavailable. Only CCD frame keys represented by at least one surviving level-2 row enter the denominator. A shared frame gives no sub-frame arrival ordering. Frame occupancy alone cannot determine particle or celestial origin.

## ACIS-S4 serial readout

ACIS-S4 can record anomalous events in one frame along one CHIPY row of one readout node. The row can change between frames. The table includes each row with multiple selected source photons in one frame anywhere in the trial. The measurement file lists singly occupied rows as well. Outside counts include every recorded level-2 event in the same node and row beyond the source aperture. Node assignments use NODE_ID.
