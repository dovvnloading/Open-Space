317 deposited Chandra leads have 164 source associations with 162 distinct Gaia DR3 identifiers. 0 source-table lookups remain unavailable.

Each association comes from the primary Gaia match or an optical position inside the X-ray 90% error circle at the event epoch. Positions without both proper-motion components use the Gaia catalog coordinates. A positional coincidence alone cannot establish the origin of a flare.

DSC values are Gaia posterior class probabilities and include the global class prior. GSP-Phot assumes a single star. Brackets give the published 16th and 84th percentiles. The variability score is a normalized rank. A missing variability row leaves variability unconstrained. These descriptions do not enter either the blind selection or the held-out test.
