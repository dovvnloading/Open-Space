# Searching for a black-hole remnant that merged a second time

The observing unit is a chronologically ordered pair of public gravitational-wave events. One component of the later binary should have the mass of the earlier remnant, within measurement uncertainty. Both signals should also come from a common sky position and luminosity distance. The analysis will test sky overlap and consistency with chance pairings. Similar masses alone cannot establish an association. The search is exploratory and a positive outcome requires an appropriate trials control.
