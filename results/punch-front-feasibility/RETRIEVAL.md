# Two-input development retrieval and review

Only the first two named CTM v0l files in receipts.json may be downloaded in full, into a new D: campaign, using the exact HTTPS URLs. Hash the complete bytes, retain size, HTTP headers and command, and create a manifest binding their ordered filenames/SHA-256, Python version and development.py SHA-256. Do not download the third file in full or decode any science array in this phase. Hashing streams bytes and does not interpret array contents. Root must independently inspect the exact reader and manifest and separately issue an authorization bearing the manifest digest before any array decode. The authorization itself has an externally supplied exact SHA-256. No alternate paths or inputs are allowed, and an existing output path is rejected.

Development is descriptive only, with no significance test, event ranking or claim. The executable requires named image and uncertainty arrays, equal units and exactly matching WCS for a fixed full common finite footprint; it otherwise fails closed. Even a successful finite-pixel result is not a validated quality mask: shared starfield/stray-light modeling and seams remain uncontrolled. Source-free and detector-frame controls, ROI, mask, prediction and thresholds need a separately reviewed future code/config freeze after development and before any prospective image. The third epoch stays sealed. No direct physical brightness-difference interpretation is supported by this preliminary reader.

L1 documentation describes flat-field, PSF and stray-light corrections, and L2 starfield/F-corona subtraction; processing can share models between frames. Its provenance table lists immediate image parents, not necessarily all calibration/reference inputs. L3 32-minute averaging can overlap: do not use it as independent validation. Independent SOHO/LASCO has a public CME catalog, but actual selected-time frame availability, WCS and coverage remain unchecked; catalog gaps cannot establish absence. See https://punchbowl.readthedocs.io/en/latest/data/data_overview.html and https://cdaw.gsfc.nasa.gov/CME_list/catalog_description.htm.
