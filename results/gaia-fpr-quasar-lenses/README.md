# Gaia FPR search for multiply imaged quasars

The search is in progress. The first run acquires the component catalogue, the quasar input crosswalk and their release dictionary. The receipts identify the exact bytes used. A measured result requires a completed screen, an explicit search denominator and checks against published systems.

The observing unit is a quasar environment. A candidate needs distinct sources with consistent colours and astrometry, a plausible lens configuration and imaging evidence for a foreground galaxy. Published candidates count as prior reports. Known lenses and random comparison fields will be carried through the selection.
