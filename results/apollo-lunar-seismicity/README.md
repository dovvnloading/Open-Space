# Apollo lunar seismicity

## Search checkpoint, 2026-11-15

Does a known externally timed disturbance leave a measurable excess or deficit of seismic events in Apollo surface records? The first test uses terrestrial shadow passages during the Apollo 17 LSPE archive. The observing unit is a distinct cataloged event, never a geophone row. Compare against the same local lunar phase on neighboring lunations and against adjacent time windows. Check waveform availability, hardware-origin signals and previously reported eclipse responses before interpreting a count difference. A second distinct question is whether individual deep moonquake nests show repeatable short-lag pairings beyond their shared tidal modulation. The eclipse and deep-event samples must be kept separate. No measurements at this checkpoint.
