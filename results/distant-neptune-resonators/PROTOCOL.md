# Distant Neptune resonance screen

Question recorded before integrating any target: which catalogued objects beyond the
7:1 resonance have an eccentricity-type orbital angle that librates with Neptune
over long intervals? The observing unit is one fitted minor-planet orbit. A
near-integer period ratio by itself is insufficient.

Freeze the JPL Small-Body Database query for asteroids with catalogued heliocentric
semimajor axis 113–400 au, perihelion 29–60 au and observed arc >720 days. Record
every returned object. Test exterior n:1, n:2 and n:3 commensurabilities in lowest
terms in a Sun + four giant planets model. Start with the nominal fits, then test
the full six-dimensional published orbit covariance for promising objects. Compare
a known resonator (2020 VN40) with circulating trial angles, and test integration
step sensitivity. Record search denominators, all survivors and time baselines.

Falsifiers include circulation in longer integrations, failure under plausible
orbit clones, and prior object-specific published identification. Report a
rediscovery or a conditional candidate when those are the strongest conclusions
the evidence permits. This is a dynamical inference from existing measurements.
