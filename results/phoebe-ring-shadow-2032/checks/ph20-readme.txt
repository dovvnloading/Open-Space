README FILE:       
------------
This ephemeris of Phoebe is based on a numerical model fitted to the 
observations dispatched from 1898 to 2019. 
This ephemeris is available  for the period [1874/07/01:2050/02/08] and through
Chebychev polynomia readable with the SPICE or CALCEPH Library .
