# Gaia DR3 binaries with massive unseen companions

No new compact object is established in this draft. The search will distinguish catalogue screens, independently tested orbits, and systems with sufficient evidence for a dark companion. Counts and results will be reported only for inputs actually processed.

Scope: public Gaia DR3 orbital solutions and independent stellar radial velocities. This analysis adds a separate results packet. It excludes the hypervelocity, JWST transient and DESI optical SETI searches.
