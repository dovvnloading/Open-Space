# Independent LAMOST DR11 velocities

The public DR11 v2.0 medium-resolution catalogue reports zero-point-corrected velocity and error from the combined blue and red spectrum (`rv_br1`, `rv_br1_err`). The catalogue repeats that measurement on the two arm rows. We queried exact Gaia DR3 identifiers in batches of 100 and preserved the returned CSV bytes, including empty responses. DR11 covers earlier releases. Each spectrum enters the analysis once. [LAMOST catalogue](https://www.lamost.org/dr11/v2.0/table/med_catalogue) · [Survey data description](https://www.lamost.org/dr11/v2.0/doc/mr-data-production-description)

We retained individual exposures with both arms, S/N ≥10 in each arm, a shared valid combined velocity, zero RV and instrument quality flags, zero fibre offset, and an object or flux-standard fibre. The local modified Julian minute is the exposure start. Subtracting eight hours converts it to UTC. We used the exact exposure times to evaluate the predicted RV, averaged model and data with identical weights within each observing night, and added a common 1 km/s nightly error in quadrature. The long-period joint fits use the weighted nightly epoch. [Exposure time definition](https://www.lamost.org/dr11/v2.0/doc/faq) · [Exposure selection and predictive checks](check_orbits.py)

We reconstructed each Gaia orbital covariance using the parameter order for its solution type, retained physically valid draws, and profiled a constant survey velocity offset. For pure astrometric solutions, both node signs are possible and the amplitude assumes that the primary traces the photocentre. The nominal chi-squared and the fraction of Gaussian Gaia draws compatible with the velocities describe orbital agreement. This fraction is conditional on the supplied Gaia error model. It measures neither the probability of a compact object nor catalogue-wide significance. [Gaia covariance conventions](https://gea.esac.esa.int/archive/documentation/GDR3/Gaia_archive/chap_datamodel/sec_dm_non--single_stars_tables/ssec_dm_nss_two_body_orbit.html) · [Measured residuals](nightly_residuals.csv)

The original and extended selections overlap. Use [the deduplicated two-screen coverage](../coverage.json) for totals. Compressed response files preserve the original server-supplied UTF-8 CSVs. Extract the extension ZIP, then decompress the individual files to verify the SHA-256 values recorded in the receipt. The scripts also read the ZIP directly.
