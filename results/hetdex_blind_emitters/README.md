# Blind rare-emitter search in the HETDEX public spectra

The search is in progress. No discovery or population limit has been established.

The observing unit is a released, source-position, PSF-weighted spectrum. Source Catalog 1 and Source Catalog 2 overlap. Independent visits, shuffled spectral extractions and synthetic injections will be distinguished from repeated reductions of the same photons. The three searches concern He II near 1640 Å, extreme rest-frame Lyα equivalent widths and extended Lyα emission, and emission with no viable conventional identification. A missing comparison wavelength leaves the associated test open.
