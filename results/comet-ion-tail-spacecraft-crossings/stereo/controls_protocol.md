# In situ controls fixed before computing composition or field summaries

For each spacecraft, use the smallest trajectory miss from a three-hour centered median of ten-minute PLASTIC velocity vectors as the event center. Use one nonoverlapping six-hour event block centered at the nearest UTC hour. Compare with fourteen six-hour windows at the same UTC hours on the seven days before and after. A missing block stays missing. Report coverage per endpoint. Restrict both event and controls to nonfill finite data. These descriptive comparisons share solar-wind structure and provide no survey-wide significance test.

For STEREO-A, compare He+ count rates in the product bins with 1 <= spacecraft-frame speed / solar-wind speed <= 2, summed over counts and valid exposure (reported counts per hour). Report any-count and spectral coverage. The counts measure helium and cannot determine source species, distinguish cometary and interstellar helium, or measure an elemental helium abundance. For both spacecraft report median proton density, proton temperature, and magnetic-field strength. Also check NASA's PLASTIC suprathermal event list for cataloged events spanning these epochs. State whether public processed singly charged O/C/N measurements exist in the sources examined.
