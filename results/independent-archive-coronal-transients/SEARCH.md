# Independent archival discovery search

Opened 2026-11-15 UTC. The initial overlap check covered the default-branch results directory and open pull requests #88, #90, #91 and #92. This working branch records new investigations. A planned test is not an observational result.

- Search public galaxy spectra for large changes in highly ionized forbidden lines across separate visits. Check flux units, ordinary narrow emission lines, aperture effects, blending and prior discoveries before interpreting any change.
- Independently examine compact spectroscopic quasar associations, separated gamma-ray burst triggers, and spatial or temporal patterns in Io volcanic activity. Each investigation needs its own observations, comparison population and prior-art check.

Only evidence that survives its relevant controls can support a scientific claim. Individual line measurements, candidate disposition and replay details will accompany any result.
